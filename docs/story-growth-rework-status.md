## 확정 규칙과 구현

- 첫 성장 행동력 100 → 아처 → 두 번째 성장 행동력 100 → 레밀리아. 두 번째 성장에는 잔여 행동력을 이월하지 않으며 휴식 비용을 1로 초기화한다. 카드·능력치·메인 및 서브 진행·골드는 유지한다.
- 시작 머리 한도 1, 메인 완주마다 +1. 첫 머리는 도감 발견 여부에 관계없이 로비에서 직접 선택한다. 본편 완주가 필요한 더 로열은 첫 선택에서 제외한다. 입문 카드도 함께 지급한다.
- 휴식은 골드 대신 행동력 1, 2, 3, 3…을 소모한다. 일반 사건 종료와 후보 재생성은 비용을 초기화하지 않는다.
- 메인은 진행 단계 4, 마지막 단계 8. N단계의 총비용은 4N+4다. 완결 핵심은 세 선택지에 동일하게 지급하고 보조 스탯으로 갈라진다.
- 연계 서브는 서브 1/2 형태로 표시한다. 현재 원고의 2단계 연계는 4+6=10이다. 메인 선행 조건을 서브 단계에 포함하지 않는다. 후속 단계가 열렸다면 후보 한 자리를 보장한다. 메인 완주 뒤에도 일반 서브는 남는다.
- 단일 서브는 행동력 1과 골드로 기본 스탯을 구매한다. 같은 사건은 개인별 1회다. 다른 플레이어가 골랐다고 내 사건을 소비하지 않는다.
- 최대 체력·피해 감소·신속·행동력 최대치·처치 골드는 현재 보상에서 제거했다. 흡혈은 완결 보상에만, 재생은 보조 효과로만 배정했다. 기존 ID는 유지하며 퇴역 보상은 추첨에서 제외한다.
- 추가 이동속도 비례 효과는 기본 이동속도를 제외한 추가 퍼센트 합계를 0~40으로 제한하고 2.5를 곱한다. 최대 추가 대미지는 100%다.
- 스킬가속은 쿨타임 감소율이 아니다. 기존 계산은 100/(100+가속), 가속 상한 300을 유지한다. 대시 재사용 감소는 최대 50%다.
- 선택 스킬 상품은 사건 선택지 화면의 ‘강화할 스킬’ 버튼으로 Q/W/E/R/A/S/D/F/C를 고른다. 지급 시 실제 선택한 키에 누적한다. 일반 공격 강화는 일반 공격 코드에만 적용한다.

## 구현상 채택한 세부값과 후속 조정 항목

아래는 문서의 미정 영역을 구현 가능하게 채운 값이다. 사용자 확정 수치와 구분해 추후 플레이테스트에서 조정한다.

- 일반 메인 진행은 작품 기본 스탯 / 공격력 4% / 스킬가속 3의 선택 구조다. 마지막 보조는 공격력 8% / 치명타 피해 16% / 스킬가속 8이다. 핵심과 중복되는 보조는 대미지 5%로 대체한다.
- 아인크라드 완결은 공격 속도 30%에 일반 공격 대미지 50%, 또는 치명타 확률 10%+피해 20%, 또는 흡혈 4%를 더한다.
- 실제 2단계 연계 완결은 설계의 3단계 기준 효과의 75%를 사용한다. 연계별로 핵심형, 핵심 75%+공격력 3%, 핵심 75%+스킬가속 3으로 구분한다. 원고에 없는 3단계 연계를 새로 만들지는 않았다.
- 기본 상품은 아래 표의 효과/가격, 집중 상품은 효과 2배/가격 2.5배다. 별도 작품당 2회 구매 제한은 추가하지 않았다. 구체적인 구매 총량 제한은 후속 결정 사항이다.
- 흡혈 회복 속도 30%는 기존 지속 흡혈의 저장량을 늘리지 않고 회복 속도를 높이며 지속시간을 줄인다. 타격당 최대 체력 10% 저장, 합산 초당 10% 회복 제한은 유지한다. 재생·포션은 가속하지 않는다. 이 상한이 흡혈 빌드에 충분한지는 실제 전투에서 조정할 항목이다.
- 사건을 마친 사냥 화면에서 ‘행동력 포기’를 누르면 남은 행동력을 버리고 보스 합류를 준비한다. 잔여 행동력 때문에 진행이 막히지 않게 하는 처리다. 조기 종료 시 남은 사냥 시간을 골드로 지급하던 보상은 제거했다.
- Arcana_B의 미등록 후속 작품 3종은 현재 게임에 새로 등록하지 않았다. 해당 자료를 실제 추가할 때 같은 정책을 적용해야 한다.
