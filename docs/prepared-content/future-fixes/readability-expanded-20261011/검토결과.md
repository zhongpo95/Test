- 나는 강조 제안을 전부 읽고 단서와 위험을 재분류했으며, 일반 동작·모호한 표현·긴 정의 문장의 강조를 제외했다. 긴 문단8사건은 추가로 직접 읽고 전환 위치를 조정했다.
- 사용자가 승인한 대표3건은 유지했다. 움직임은 렌지 대사 일부의 선택적 브라우저 비교만 유지하고 다른 사건에 추가하지 않았다.

## 유지한 내용

원문의 공백을 제외한 모든 글자와 순서가 같다. 선택지·보상·수치·조건·카드 효과는 수정하지 않았다. 32개 원본 JSON 파일의 전체 SHA가 그대로다. 선택지 결과, 머리 소개, 카드 툴팁은 이번 본문 편집 범위 밖이며 생성되는 별도 입문 사건도966건에 포함하지 않는다.
