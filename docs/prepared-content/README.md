# A·B 사건 가독성 준비본

현재 테스트를 유지하면서 나중에 통합할 수 있도록 승인된 편집안을 보존한다. 병합해도 게임 데이터나 UI 동작은 바뀌지 않는다.

- [전체 사건 전후 비교](future-fixes/readability-expanded-20261011/전체사건_전후비교.html). 파일을 내려받아 브라우저에서 연다.
- [검토 결과](future-fixes/readability-expanded-20261011/검토결과.md).
- [적용 안내](future-fixes/readability-expanded-20261011/추가방법.md).
- [제외·수정 이유](copy_archive/readability-expanded-20261011/판단이유.md).

A 28종의 사건 879건, 공통 13건, B 3종의 사건 74건을 합쳐 966건이다. 본문 문단 변경 332건과 강조가 있는 사건 219건을 준비했다. 머리카드 소개, 선택지 결과, 카드 설명, 생성되는 입문 사건은 대상이 아니다.

proposal.json과 미리보기는 승인된 로컬 준비본 그대로다. 원래 검토 문서의 'PR 미생성'은 준비 당시의 기록이며 이 PR은 그 결과의 보존·검토용 전달이다. JSON의 절대 경로와 해시는 당시 출처 증거이며 다른 컴퓨터에서 그대로 실행하는 경로가 아니다. 요청과 원응답은 함께 보존하되 로컬 Gemma 실행기는 이 패키지의 실행 의존성으로 제공하지 않는다.

실제 통합 전 최신 사건 본문과 key를 대조해야 한다. 기존 87필드 교정 등으로 본문이 달라졌다면 덮어쓰지 않고 다시 편집한다. 강조 메타데이터는 게임용 색상 태그가 아니므로 표시 코드 연동이 따로 필요하다. 이 PR은 맵·ASI·이미지를 생성하거나 설치하지 않는다.

검증은 데이터 보존, 강조 구절 일치, 검토 응답 완결성, HTML 스크립트 구문과 파일 동일성까지다. 게임 컴파일·Warcraft/JN 실행·멀티플레이 및 전체판의 자동화된 시각 검사는 수행하지 않았다.
