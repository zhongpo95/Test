# 사건 가독성 편집의 제외·교정 기록

첫 대량 검토는 긴 사건까지 전부 한 문단으로 합쳐 승인한 방식과 맞지 않아 채택하지 않았다. first-pass-requests와 rejected-first-pass에 요청·원응답·실행기를 보존했다. 진행 중이던 첫 방식의 실행은 중단하고 문장 번호 기반 검토로 전환했다.

rejected.json에는 잘못된 마지막 문장 경계, 원문에 없는 강조 구절, 긴 문장 전체 강조, 수동 변경 전 강조를 기록했다. 같은 사건에 여러 기록이 있을 수 있으므로 기록 수를 폐기 사건 수로 세지 않는다.

editor-overrides.json은 단서·감정·위험 재분류와 일반적인 표현의 강조 제외를 담는다. paragraph-overrides.json은 긴 문단을 직접 읽고 추가한 화제 전환 위치다. 원문 내용·순서·보상은 변경하지 않았다.

기존 파일과 원응답은 삭제하지 않았다. 운영 반영은 하지 않았으며 이 보존본을 게임 데이터로 가져오지 않는다.
