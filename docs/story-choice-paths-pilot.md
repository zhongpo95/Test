# 선택으로 열리는 서브 사건 시범 적용

2026-10-31. 참조 대화 `01a1895c-b382-7f32-ab8e-120d3699b62e`의 마지막 설계를 구현한다.

## 범위

페나코니 연결 두 사건을 먼저 이관한다. 선택 구조는 공통 시스템에 적용한다. 미연결 단일 서브·연계·후일담 원고와 기존 보상은 삭제하지 않지만 무작위 후보로는 나오지 않는다. 따라서 전체 콘텐츠 배포판이 아니라 실게임 평가를 위한 시범 브랜치이다. 다른 작품의 서브 연결은 이 시범의 실플레이 평가 이후 진행한다.

메인 행동력·완결 보상·사냥·보스 진행 수치는 유지한다. 재추첨/휴식 action 2300은 자원 소모 없이 무시한다. 메인 완주 뒤 다음 머리는 별도 작품 목록에서 확정 선택하며, 페이지 이동은 비용이 없다. 기존 머리 한도와 선행 완주 조건은 유지한다.

## 페나코니 재현

1. 페나코니를 출발 머리로 골라 메인 4장 `hsr_main_04`까지 진행한다.
2. 두 번째 대답으로 서로 다른 안내를 나중에 확인해 달라고 부탁한다. 대화 반응 도중에는 열리지 않고 최종 정산 뒤에만 개방된다.
3. 다음 사건 목록에 메인 5장과 「서로 다른 얼굴의 안내인」이 함께 뜬다. 서브 선택 시 행동력 4를 소비한다.
4. 서브의 두 번째 대답을 고르면 「기억에 남겨 둔 출구」가 열린다. 다음 목록은 같은 메인 5장과 후속 서브이다. 후속 비용은 6, 연계 전체 비용은 10이다.
5. 갈림길에서 메인을 고르면 열린 서브는 이번 원정에서 포기 처리된다. 포기한 서브는 재개방되지 않는다.
6. 반대로 첫 메인 4장 대답에서 1번이나 3번을 골랐다면 서브가 열리지 않는다.

서브는 블랙 스완과 기억을 대조하는 원정용 창작 사건이다. 원작에 존재하는 퀘스트로 주장하지 않는다. 다른 인물이 해당 시점에 현재 장소에 동행하는 묘사는 제거했다. 보상 카드 연결과 수치는 유지했다.

## 상태와 확장 방법

- `ProtoSideState[ProtoStoryKey(pid,id)]`는 0 잠김, 1 개방, 2 포기, 3 선택이다. 기존 성공/실패 선택 이력과 분리한다.
- 성공한 최종 `ProtoResolve` 정산에서만 연결을 연다. `ProtoAction`의 유효한 사건 선택이 행동력을 차감하기 직전에 열린 다른 기회를 포기 처리한다.
- 후보 갱신, 목록 조회, 오래된 동기화 요청, 행동력 부족, 후보 제한시간 만료는 기회를 포기하지 않는다. 후보 시간 만료는 사냥으로 복귀한다.
- 보스전 뒤 두 번째 성장에서는 행동력 100을 채우고 열린/포기 상태를 유지한다. 새 원정은 기회 상태를 지운다.
- 다른 작품에 추가할 때 해당 서브 JSON에 `choicePath: true`, `previous`, 양수 `previousChoice`를 명시한다. 선행 대답 하나에서 최대 3개 서브까지 연결한다. 서브를 추가로 연결할 때 선행 사건도 실제로 접근 가능한지 확인한다.
- `node tools/generate-prototype-content.cjs`가 개방 문구와 분기별 첫 서브/다음 서브 연결을 생성한다. 정산에서 전체 사건을 반복하지 않고 해당 분기에 연결된 서브만 조회한다.
- 실제 후보 수는 `ProtoOfferCount`로 표시한다. 기존 후보 수 능력치 배열에 화면 상태를 덮어쓰지 않는다.
- 서브 전체 원고를 자동으로 메인에 붙이지 않는다. 작품 시점, 대답의 의미, 다음 메인과의 양자택일 이유를 검토한 뒤 연결한다.
