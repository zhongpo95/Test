## 변경과 적용

본문을 결과 영역에서 사용 중인 ExpUILabel의 TEXT로 표시한다. TEXTAREA 생성과 TOC 로드를 중단한다. 문단·강조색·본문 캐시·행동 상세 복귀는 유지한다. 기존 FDF/TOC 파일은 남아 있으나 호출하지 않으며 다시 임포트할 필요가 없다. UI 코드만 적용한다.

TEXTAREA의 자동 줄 간격 0.002는 이번 변경에 적용되지 않는다. 이번 범위는 글자의 선명도 복구이며 자동 줄 간격 확대를 완료했다고 보지 않는다. 임의 줄 분할이나 높이 측정으로 본문을 숨기는 처리는 추가하지 않는다.

## 검증

실제 JASS 함수의 TEXT 생성, FDF 미호출, 문단·강조색 유지, 캐시와 상세 복귀를 모의 검사한다. 수정 후 Warcraft 실행과 시각 검증은 미실행이다. 맵과 ASI를 생성하지 않는다.
