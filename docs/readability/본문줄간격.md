# 사건 본문 표시 복구

PR #197의 행 단위 줄 간격 처리는 사용자 게임 화면에서 본문이 사라지는 회귀가 확인되어 철회했다. 기존 단일 TEXT의 자동 줄바꿈으로 복구했고 PR #196의 문단·색상·보상 개선은 유지한다.

철회 코드와 검사 한계는 copy_archive/20261011-story-spacing-regression/판단이유.md에 보존했다. 실제 엔진의 높이 측정이나 글리프 잘림 원인은 아직 확정하지 않았다. 별도 행 프레임을 사용하지 않으므로 해당 측정 경로에는 더 이상 의존하지 않는다.

맵과 ASI는 만들지 않았다. 수정 소스로 다시 빌드해 플레이해야 한다. 실제 인게임 재검증은 필요하다.
