# 사건 본문 표시 수정

## 실제 맵 확인

`C:\Users\ctqho\OneDrive\Documents\Warcraft III\Maps\mm\2\ARCRPG_Siegfried_Preview_v27_slim.w3x`에서 FDF의 그림자 알파/오프셋 0과 JASS의 DzFrameSetFont 플래그 0을 모두 확인했다. 즉 검사한 맵에는 #200이 포함되어 있다. 최근 실행 맵과의 동일성은 리플레이로 확정하지 못했다. 원본 맵은 변경하지 않았다.

## 변경과 적용

본문을 결과 영역에서 사용 중인 ExpUILabel의 TEXT로 표시한다. TEXTAREA 생성과 TOC 로드를 중단한다. 문단·강조색·본문 캐시·행동 상세 복귀는 유지한다. 기존 FDF/TOC 파일은 남아 있으나 호출하지 않으며 다시 임포트할 필요가 없다. UI 코드만 적용한다.

TEXTAREA의 자동 줄 간격 0.002는 이번 변경에 적용되지 않는다. 이번 범위는 글자의 선명도 복구이며 자동 줄 간격 확대를 완료했다고 보지 않는다. 임의 줄 분할이나 높이 측정으로 본문을 숨기는 처리는 추가하지 않는다.

## 검증

실제 JASS 함수의 TEXT 생성, FDF 미호출, 문단·강조색 유지, 캐시와 상세 복귀를 모의 검사한다. 수정 후 Warcraft 실행과 시각 검증은 미실행이다. 맵과 ASI를 생성하지 않는다.

## 문단 여백 개선

일반 TEXT 한 개를 유지하고 표시 문자열에만 여백을 적용한다. 기존 빈 줄이 있는 문단은 빈 줄을 하나 더 넣고, 문단 구분이 없는 짧은 소개는 첫 `. ` 뒤를 빈 줄로 나눈다. 자동 줄바꿈의 행간은 변경하지 않는다. 원본 사건 데이터와 강조색은 유지한다.

문자열 길이 900 초과 또는 기존 `|n` 6개 이상이면 원문 간격을 유지한다. 이는 보수적 제한이며 실제 폰트 높이나 모든 본문의 화면 수용을 보장하는 검사는 아니다. 변경된 원문이 들어올 때만 처리하며 동일 문자열 갱신에는 재처리하지 않는다.

FDF·TOC 임포트와 ASI 교체는 불필요하다. JASS 컴파일 통과(기존 억제 진단 24개), 문단/한글/강조색/캐시/복귀 모의 검사 및 기존 UI 18개 그룹 통과. 게임 내 시각 검사와 긴 본문 잘림 확인은 미실행이다.
