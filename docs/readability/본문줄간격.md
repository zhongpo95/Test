# 사건 본문 FDF 줄 간격

사건 본문과 행동 상세에 전용 TEXTAREA를 사용한다. 글꼴 크기와 줄 높이는 0.011, 줄 간격은 0.002, 안쪽 여백은 0.002다. 문단과 강조색은 원문 그대로 전달한다. 선택지와 결과 보상 영역의 배치는 변경하지 않는다.

## 맵에 추가할 파일

저장소의 다음 두 파일을 맵에 임포트하고 사용자 지정 경로를 정확히 지정한다.

- `war3mapImported/Arcana_EventStory.fdf` → `war3mapImported\Arcana_EventStory.fdf`
- `war3mapImported/Arcana_EventStory.toc` → `war3mapImported\Arcana_EventStory.toc`

`UI/UI_ExpeditionPrototype.j`도 함께 적용해야 한다. ASI 교체나 이미지 추가는 필요 없다. 이 작업에서 맵을 생성하지 않는다. FDF는 게임 내장 `UI\FrameDef\UI\EscMenuTemplates.fdf`의 스크롤바 템플릿과 기존 `Fonts\DFHeiMd.ttf`를 사용한다.

## 동작과 한계

32개의 TEXT로 분할하던 PR #197의 처리를 제거한다. 빈 원본을 먼저 표시하는 경로도 제거한다. TEXTAREA를 만들지 못해 핸들 0이 반환되면 기존 TEXT로 표시한다. 이 대체 경로는 FDF 구문 오류로 엔진이 중단되는 경우까지 보장하지 않으므로 두 파일을 반드시 함께 임포트한다.

같은 본문은 다시 설정하지 않아 반복 갱신에 따른 스크롤 초기화를 줄인다. 긴 본문에는 기본 스크롤바를 사용한다. TEXTAREA가 긴 글 설정 시 아래쪽에서 시작하는 엔진 동작은 실제 게임에서 확인해야 한다. 기본 높이를 FDF에 지정해 높이 0으로 생성되지 않게 한다.

## 검증 범위

`node tools/check-story-line-spacing.cjs`는 실제 JASS 함수를 모의 실행하여 생성 인자, 핸들 0 대체, 문단·색상, 캐시, 상세에서 원문 복귀를 확인한다. FDF의 경로와 필수 속성도 정적으로 검사한다. 이 검사는 게임의 FDF 파싱·줄바꿈·스크롤 표시 검증을 대신하지 않는다.

게임 확인 항목은 일반 사건, 연속 대화, 머리카드 결과에서 본문 표시, 행동 상세 진입/복귀, 긴 본문 스크롤, 선택지 클릭이다. JASS 컴파일은 FDF 문법을 검사하지 않는다.

## 이번 변경의 검증 결과

- 정적 검사와 JASS 함수 모의 검사 통과.
- 기존 UI 시나리오 18개 그룹 통과.
- JASSHelper/PJASS 종료 코드 0. 기존 억제 진단 24개 존재.
- 게임 실행·FDF 엔진 파싱·시각 검사는 미실행. 맵 및 ASI 생성 없음.

## PR #199 게임 확인 후 글꼴 보정

사용자 스크린샷에서는 본문이 표시되지만 오른쪽 TEXT와 달리 검은 그림자/외곽선처럼 뭉개져 보였다. 원인 확정이 아닌 보정으로 FDF에 그림자 투명도와 오프셋 0을 명시하고 생성 직후 DzFrameSetFont 플래그 0을 적용한다. 줄 간격과 글꼴 크기는 유지한다.

수정된 FDF를 기존 `war3mapImported\Arcana_EventStory.fdf`에 덮어 임포트하고 UI 코드도 함께 적용한다. TOC 내용은 동일하다. 정적/모의 검사와 JASSHelper/PJASS는 통과했으며 기존 억제 진단 24개가 있다. 수정 후 실제 게임 표시 개선은 아직 확인하지 않았다. TEXTAREA는 일반 TEXT 속성 지원이 제한되므로 FDF 설정만으로 해결됐다고 판단하지 않는다.
