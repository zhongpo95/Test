# 사건 가독성 실제 적용

PR #195의 문단·강조 준비안을 실제 생성기와 JASS UI에 연결한다. 현재 main에 포함된 머리카드 28종과 공통 사건 892건을 대상으로 한다. B 신규 콘텐츠는 이번 변경으로 활성화하지 않는다.

## 변경

- 원고 332건의 문단을 승인된 편집안으로 교체했다. 공백 외 문자는 동일하다.
- content/event-readability.json의 승인된 구절을 인물 이름보다 먼저 강조한다. 인물·단서뿐 아니라 약속, 편지, 기억 등 장면 소재도 강조 후보로 사용한다. 현재 사건 본문 813건에 색상이 들어간다. 무조건 첫 단어를 색칠하거나 문장 전체를 채우지는 않는다.
- 같은 생성 규칙을 머리 소개, 선택지, 반응·결과, 실패 문구와 엔딩 카드 설명에 연결했다. 문단 편집은 사건 본문이며 다른 문구는 내용 변경 없이 강조와 표시 계층을 개선했다.
- 행동 아래 보상을 별도 행과 녹색으로, 비용·변화를 따로 표시한다. 신규·중복 보상 모두 효과명을 보여준다.
- 결과는 행동과 결과 서술 사이에 빈 줄을 둔다. 카드 툴팁은 획득 횟수·현재 합산 효과·이번에 얻는 효과를 구분한다.
- 종이 배경에는 어두운 강조색을, 카드 보관함의 어두운 배경에는 밝은 강조색을 사용한다. 본문과 툴팁에 확보한 높이를 늘렸다.

강조 문자열은 생성 단계에서 만들어 배열에 저장한다. 게임 중 전체 사건 탐색이나 새 타이머는 추가하지 않았다. 글자 흔들림은 이번 구현에 포함하지 않는다.

## 검증

- node tools/check-event-readability.cjs — 892건의 본문 문자 보존, story 외 데이터 동일, 카드·사건 ID 보존, 승인된 구절 우선 적용과 이름 오인 강조 방지 확인.
- node tools/generate-prototype-content.cjs --check — JSON과 생성 JASS 일치.
- node tools/check-story-dialogue.cjs — 대화 분기·보상·엔딩·등록 ID 검사 통과.
- node tools/check-expedition-ui.cjs — 기존 모의 UI 18개 그룹 통과. 실제 화면 렌더링 검증은 아니다.
- JASSHelper 및 PJASS 종료 코드 0. 기존 도구 출력의 억제 진단 24개가 남아 있다. 진단 0개로 해석하면 안 된다.
- 인게임 시각·입력·멀티플레이 검사는 미실행이다. 폰트별 실제 줄바꿈과 긴 보상 두 장의 툴팁은 플레이 검증이 필요하다.

## 적용

main 병합 후 맵 제작 시 변경된 content/roguelite, 생성기, Data_PrototypeCatalog.j, Data_Prototype.j, ExpeditionPrototype.j, 두 UI 파일을 함께 사용한다. 이번 PR은 실제 코드 변경이지만 맵을 제작하거나 설치한 것은 아니다. 기존 실행 중인 맵은 자동으로 바뀌지 않는다. 새 텍스처와 ASI 갱신은 필요하지 않다.

B의 강조 구절도 메타데이터에 보존했다. B를 나중에 통합할 때는 승인된 문단을 먼저 적용하고 본문 일치 여부를 검사해야 한다. 기존 원문과 일치하지 않는 강조는 자동으로 덮어쓰지 않는다.
