# 헤라 이식용 모듈 v19

hera_text_width.lua와 controls/text.lua는 명시적 줄바꿈 및 근사 높이를 제공한다. uifunc.lua는 글자와 배경 크기를 맞추고 화면 경계를 보정한다.
yuansheng/native.lua는 실제 배치한 버튼 좌표를 hera_native_tooltip.lua에 전달한다. tooltip.lua는 엔진 툴팁 높이를 읽지 않고 아래 모서리를 배치한다. 기존 아이템 콜백과 엔진 명령 설명을 사용한다.
게임 시각 검사는 사용자 확인 대기다. 몬스터 생성과 누락된 유닛 이름·투사체 API는 아직 미해결이다. ../Hera_RPG_Init_README.md와 ../hera-v19-evidence.json을 참고한다.
