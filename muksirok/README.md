# 묵시록 0.1.6b 포트

`hera-port`는 기존 묵시록 초기화 맵의 한국어화·진단 오버레이에 공식 0.1.6b 변경을 합친 Lua 소스입니다. 게임의 원본 보호 파일과 기존 v160 맵은 수정하지 않습니다.

공식 0.1.6b 변경 로그의 12개 항목을 반영했습니다. 외침 도구와 채팅 동기화, 나에기 마코토와 피 묻은 챔피언 벨트 조정, 악마 혈통 변신, 초기 칼 사용 시점, 시작 웨이브 준비 판정, 난이도별 체력·공격력, 기계 팔 수치, 단간론파 수사 장소 임무 삭제, ZUN의 추가 종결 피해 계산, 단테 총기 전환 재사용 대기시간, 정화 약제의 일반 보급상자 의료 목록 배치가 포함됩니다. 공식판의 아이콘 Alt+클릭 외침 코드는 포함하지만 해당 기능의 기본 플래그는 공식판처럼 꺼져 있습니다.

삭제된 장소 수사 모듈의 기존 소스는 `copy_archive`에 보존하며 활성 Lua 패키지에서는 제외합니다. 공식 0.1.6b의 `Units/AbilityData.slk` 변경도 빌드 시 이전 자산에 정확한 두 셀 변경을 적용하고 공식 파일 해시와 대조합니다.

T키 이모티콘은 누름·뗌을 직접 등록하고 Lua 브리지에 함수 호출식으로 전달합니다. v166은 v165 로그에서 선택 방향이 계속 0으로 남은 문제를 해결하기 위해 아르카나 맵처럼 30ms 게임 타이머로 커서 방향을 갱신합니다. 선택창은 처음부터 숨기고 T키를 누를 때 표시하며, 입력 좌표와 선택 방향을 진단 로그에 기록합니다. v161의 외침 도구가 설치 환경에 없는 편집창 이벤트 함수를 호출해 초기화를 막던 문제를 헤라 UI 브리지의 편집창 이벤트 연결로 수정했습니다. `build_hera_rpg_v166.py`는 기존 v160 복원 자산이 있는 `HERA_ASSET_ROOT`를 읽고 별도 `Hera_RPG_Init_v166.w3x`를 생성합니다. 이 복원 자산과 원본 맵은 저장소에 포함하지 않습니다. 원본에 있던 보호된 실행 파일·로더는 빌드 과정에서 제외합니다.

v167은 방향 선택 로그의 좌표와 선택값이 어긋나던 문제를 바로잡기 위해 마우스 이동의 가로·세로 크기와 부호로 좌·상·우·하를 판정합니다. `build_hera_rpg_v167.py`는 별도 `Hera_RPG_Init_v167.w3x`를 생성합니다.

Lua 5.3 문법 검사, 생성 맵의 MPQ 재열기, 오버레이 Lua 파일의 패키지 내 해시 비교를 수행했습니다. 실제 Warcraft 실행, 멀티플레이 동기화, 화면 검사는 수행하지 않았습니다.
