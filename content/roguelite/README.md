# 메인 사건 다단계 대화 적용

## 동작

13개 머리카드의 메인 사건 198개에 검수 원고를 적용했다. 첫 선택의 반응을 읽은 뒤 중요한 장면은 후속 선택으로 이어지며, 대화가 끝나야 카드 보상·사건 이력·메인 진행·서사 카드 변화가 확정된다.

추가 대화 71단계와 엔딩 대화 13단계를 사용한다. 후속 대화는 추가 행동력이나 보상을 발생시키지 않는다. 기존 일반 사건과 머리카드 입장 사건은 기존 처리를 유지한다.

최종 사건은 기존 세 보상 대신 지역별 공통 엔딩 카드 한 장을 지급한다. 페나코니는 선데이 격파 뒤 질문과 단일 대답을 거쳐 지급한다.

- 선데이. 대체... 생명은 왜 깊은 잠에 빠지는 건가?
- 개척자의 단일 대답. 왜냐면... 언젠가... 우린 꿈에서 깨어날 거니까

엔딩 카드 13종은 현재 기념 카드이며 전투 효과는 미설정이다. 기존 카드 수치를 임의로 바꾸지 않았다. 교체된 마지막 보상 39종의 정의는 ID와 기록 보존을 위해 남겨두되 신규 지급 대상에서 제외했다. 새 엔딩 카드는 기존 전체 카드 ID 뒤에 배치한다.

## 원고와 생성

`*.json`은 적용 원고다. 검수본의 Gemma 기록 ID와 출처 해시는 적용 증빙에 남긴다. ‘일리야’ 표기는 ‘이리야’로 정정했다.

카탈로그는 다음 명령으로 생성하고 일치를 확인한다.

```powershell
node tools/generate-prototype-content.cjs
node tools/generate-prototype-content.cjs --check
```

## 검증 범위

검증 보고서에서 JSON 참조·ID 보존·생성 결과, 실제 JASS를 변환해 실행하는 모의 검사, JassHelper/pjass 컴파일 결과를 구분한다. 모의 검사는 Warcraft 엔진의 프레임 표시나 실제 멀티플레이 검증을 대신하지 않는다. 이번 적용은 소스 변경이며 맵 파일을 생성하지 않는다.

이번 적용에서 JSON·생성 검사, 198개 사건의 최초 선택 594경로를 포함한 모의 검사 7묶음, Vexorian JassHelper와 PJASS 검사를 통과했다. 두 컴파일 검사 종료 코드는 0이며 기존 `24 errors ignored` 표시는 유지되었다. 보스 합류 시에는 기존 정책대로 진행 중인 사건을 안전한 기본 선택으로 끝까지 정산한다.
