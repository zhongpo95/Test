# 메인 사건 다단계 대화 적용

## 동작

현재 머리 카드 28개, 메인 사건 401개, 입장 사건을 제외한 사건 892개, 카드 보상 정의 1,653개를 사용한다. 머리 추가 제작을 멈추고 기존 이야기·표시 문구·이미지를 다듬는 상태다. 첫 선택의 반응을 읽은 뒤 중요한 장면은 후속 선택으로 이어지며, 대화가 끝나야 카드 보상·사건 이력·메인 진행·서사 카드 변화가 확정된다.

엔딩을 포함한 추가 대화 150단계를 사용한다. 후속 대화는 추가 행동력이나 보상을 발생시키지 않는다. 머리 입장 비용은 행동력 0이다. 플레이어별 입장 정의 112개를 합친 전체 사건 정의는 1,004개다.

머리 한도는 이번 원정에서 2장으로 시작한다. 각 머리의 메인 이야기를 처음 끝까지 정산할 때 한도가 1장 증가하고 기존 머리는 유지된다. 새 원정에서는 완료 기록과 증가한 한도가 초기화된다. 페르소나 5 더 로열은 이번 원정에서 본편 메인을 완주한 뒤에만 후보 자격을 얻는다. 즉시 지급이나 다음 후보 확정 등장은 아니며, 영구 발견 도감으로 완주 조건을 건너뛸 수 없다.

최종 사건은 기존 세 보상 대신 지역별 공통 엔딩 카드 한 장을 지급한다. 페나코니는 선데이 격파 뒤 질문과 단일 대답을 거쳐 지급한다.

- 선데이. 대체... 생명은 왜 깊은 잠에 빠지는 건가?
- 개척자의 단일 대답. 왜냐면... 언젠가... 우린 꿈에서 깨어날 거니까

엔딩 카드 28종은 현재 기념 카드이며 전투 효과는 미설정이다. 기존 카드 수치를 임의로 바꾸지 않았다. 초기 13개 지역에서 교체했던 마지막 보상 39종의 정의는 ID와 기록 보존을 위해 남겨두되 신규 지급 대상에서 제외했다. 새 카드는 기존 전체 카드 ID 뒤에 배치한다.

## 원고와 생성

`*.json`은 적용 원고다. 검수본의 Gemma 기록 ID와 출처 해시는 적용 증빙에 남긴다. ‘일리야’ 표기는 ‘이리야’로 정정했다.

품질 교정은 소개 12개, 카드 키워드 269개와 사건 그림 5종의 구도에 적용했다. 이 중 실제 효과와 어긋난 키워드는 21개이며, 나머지는 조건과 불이익을 분명히 하는 편집이다. 수치·보상 재분배는 하지 않았다. 원문과 기각 이유는 `copy_archive/quality_polish_20261010`, 검토·검증 기록은 `content/reviews/quality-polish-20261010` 및 `content/reviews/next-priority-heads-20261010`에 보존한다.

이미지 원본과 실제 회차·게임 장면, 대표 인물 그림을 구분해 기록한다. 모든 대표 그림을 해당 사건의 실제 장면이라고 취급하지 않는다. 추가 텍스처는 `D:\Work\ARCANA\war3mapImported`, 배포 이미지 팩은 `D:\Work\ARCANA\Arcana_A.asi`를 사용한다. 교정한 그림은 같은 임포트 경로를 유지한다.

카탈로그는 다음 명령으로 생성하고 일치를 확인한다.

```powershell
node tools/generate-prototype-content.cjs
node tools/generate-prototype-content.cjs --check
```

## 검증 범위

검증 보고서에서 JSON 참조·ID 보존·생성 결과, 실제 JASS를 변환해 실행하는 모의 검사, JassHelper/pjass 컴파일 결과를 구분한다. 모의 검사는 Warcraft 엔진의 프레임 표시나 실제 멀티플레이 검증을 대신하지 않는다. 이번 적용은 소스 변경이며 맵 파일을 생성하지 않는다.

최종 적용에서 JSON·생성 검사, 메인 401개와 최초 선택 1,203경로를 포함한 정적·모의 검사 11묶음, Vexorian JassHelper와 PJASS 검사를 통과했다. 두 컴파일 검사 종료 코드는 0이며 기존 `24 errors ignored` 표시는 유지되었다. 보스 합류 시에는 기존 정책대로 진행 중인 사건을 안전한 기본 선택으로 끝까지 정산한다. 실제 화면·입력·멀티플레이·등장 빈도와 밸런스·Warcraft VM 실행 한도는 별도 검증이 필요하다.
