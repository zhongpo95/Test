# 개인 사냥 UI 정적 미리보기

`tools/preview-hunt-ui.cjs`가 실제 JASS UI 콜백을 모의 실행한 프레임 좌표·문자열을 추출하고, `tools/render-hunt-ui.py`가 원정 전용 TGA와 맑은 고딕을 조합한다.

- 출발 준비·4인 파티, 사건 후보 3개·4개, 행동 4개, 능력치·전체 효과, 보유 카드 1장·4장·24장·50장·2페이지·아이콘 툴팁의 13개 화면을 점검했다.
- 인물별 새 아이콘은 제작하지 않았고 현재 등록된 지역 아이콘을 사용한다. 미리보기에서 로컬 파일이 없는 Warcraft 기본 아이콘은 `아이콘` 자리표시자로 표시한다.
- 수치는 모의 실행 예시다. 무기·치명·체력 등 네이티브 조회는 게임 실행 결과가 아니며 프레임 겹침·폰트·줄바꿈도 Warcraft에서 재확인해야 한다.
- I키 보관함은 보유 카드 50칸, 지역순·희귀도순 정렬, 효과명·강화·각성 정보를 호버 툴팁에서 제공한다. 목록은 카드 획득·강화·각성·런 변경 또는 정렬 변경 때 갱신한다.
- 사건 등급은 해당 사건이 줄 수 있는 카드의 최고 등급이다. 보상 확정 표시가 아니며 성공률과 비용은 행동 선택에서 별도로 확인한다.

Windows에서 실행한다.

```powershell
node tools/preview-hunt-ui.cjs
python -B tools/render-hunt-ui.py "$env:TEMP/arcana-hunt-ui-frames.json"
```

`text-fit.json`은 선택한 13개 화면의 추정 글자 영역 초과 목록이다. 전체 콘텐츠나 게임 폰트 검증을 뜻하지 않는다.

Tab은 중앙의 능력치 전용 패널, I는 보유 카드 전용이다. 전체 화면을 덮지 않는다. 공통 지도·선택지 메뉴는 각 창에서 숨긴다. I키 창은 10열×5행 아이콘 격자이며 큰 이미지 영역은 제거했다. 효과·강화 배율·각성 조건은 아이콘 호버 툴팁에서 확인한다. 작품별 아이콘 연결은 다음 작업으로 남긴다.

새 텍스처와 임포트 방법은 [원정 UI 텍스처 적용 안내](../polish/README.md)를 참고한다. 미리보기는 인게임 캡처가 아니다.
