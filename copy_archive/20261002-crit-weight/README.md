# 치명타 보상 비율 변경 전 원본

기본 치명타가 2배이고 카드 치명 피해가 누적되며 지나치게 커지던 수치를 보존한다. 이 폴더는 활성 입력이나 Import 대상이 아니다. 출처 커밋, 원본 SHA-256과 변경 수치는 manifest.json에 기록했다. 기존 생성 JASS와 검토 목록은 보존한 JSON에서 재생성할 수 있다. 기존 사건 이야기와 다른 능력치는 폐기하지 않는다.

승인한 기준은 기본 추가 피해 +50%(총 1.5배), 치명 확률 +2%p와 치명 피해 +4%p를 같은 수치 예산으로 보는 것이다. 이 비율은 기대 피해 증가가 같다는 수학적 주장이나 한 카드에 두 능력치를 반드시 함께 넣는 규칙이 아니다.
