# 줄 간격 구현 철회 기록

PR #197 적용 후 사용자가 행동 선택과 사건 결과 화면에서 왼쪽 본문이 사라진 현상을 확인했다. 이 폴더는 해당 코드·모의 검사·당시 문서를 보존한다. 게임에 가져오지 않는다.

확인된 설계 결함은 기존 본문을 먼저 비우고 숨겨진 TEXT의 높이를 신뢰해 매우 작은 TEXT 행으로 대체한 것이다. 측정값이 양수인 것만으로 실제 글리프가 표시되는지 보장하지 못하며, 실패한 표시 상태도 캐시한다. 모의 검사는 임의로 정상 높이를 반환했으므로 실제 엔진의 글리프 잘림과 숨겨진 프레임 측정 문제를 검증하지 못했다.

사용자 화면과 코드로 표시 경로 회귀는 확인했으나 실제 엔진의 측정값·프레임 상태 로그가 없으므로 특정 native 오류를 확정하지 않는다.

수정은 UI를 PR #196 병합 시점 e8e3e9a의 단일 TEXT 경로로 정확히 복원한다. 본문 문단·강조·보상 설명 데이터는 유지한다. 약 3px 줄 간격 추가만 철회하며, 실제 JN 폰트 측정 검증 전 다시 활성화하지 않는다.
