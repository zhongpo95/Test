# 사건 본문 줄 간격

글꼴 크기 0.011을 유지하면서 사건 본문과 행동 상세의 줄 사이에 0.002 화면 단위 여백을 추가한다. 세로 900px 게임 영역에서는 약 3px다. 문단의 빈 줄은 기본 줄 높이의 60%로 유지한다.

구형 JN에 줄 간격 설정 API가 없어 재사용하는 TEXT 프레임 32개를 사용한다. 숨겨진 TEXT의 실제 자동 줄바꿈 높이를 측정하며 문자열이 같으면 재배치하지 않는다. 색상 태그는 다음 줄로 이어진다. 입력 프레임과 동기화 로직은 변경하지 않는다.

높이를 얻지 못하거나 본문이 영역을 넘거나 한 단어가 폭을 넘으면 기존 TEXT 표시로 돌아간다. 따라서 게임에서 간격이 그대로면 원문 길이와 자동 높이 측정 지원 여부를 확인해야 한다. 신규 텍스처나 ASI 교체는 필요 없다.

검증은 실제 JASS 함수 모의 실행으로 간격·색상 유지·문단·캐시·넘침 복원·재진입을 확인했다. 기존 UI 모의 18그룹과 JASSHelper/PJASS 컴파일도 통과했다. 기존 억제 진단 24개는 남아 있다. 실제 Warcraft/JN 폰트 측정과 시각 검사는 미실행이며 맵은 만들지 않았다.
