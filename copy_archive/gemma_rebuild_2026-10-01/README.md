# 사건·카드 재제작 보관 안내

이 폴더는 활성 콘텐츠가 아니다. 기존 콘텐츠의 원본, 생성 요청, Gemma 응답과 채택 전후 검토본을 보존한다. 사용자 지시에 따라 폐기한 내용도 삭제하지 않는다.

- `before_rewrite/`. main `067d5d68cc9db8acf15c94b09d73d99c497c2eb8` 기준 교체 전 11개 파일. manifest의 SHA-256은 보관 파일의 실제 바이트 기준이다.
- `requests/`. 모델에 전달한 질문·정의·설정 범위. 재검토 입력도 포함한다.
- `drafts/`. 원본 응답, 요청, 모델 옵션과 소요 시간. 검토를 통과하지 않은 내용을 포함한다.
- `reviews/`. Gemma의 평가 원문. 모델 판정을 검증 완료로 취급하지 않는다.
- `revisions/`. Codex 수정본, 수치 계획 및 추가 수정 이전의 원문. 일회성 결합 스크립트는 당시 작업 과정을 보존하는 용도다.

실제로 로드하는 데이터는 `content/roguelite/*.json`과 그것에서 생성한 `Data/Data_PrototypeCatalog.j`이다. Import.j는 이 보관 폴더를 참조하지 않는다. 새 맵 파일은 만들지 않았다.

머리별 확장은 [확장 계획](../../md/roguelite/머리별%20사건%20확장%20계획.md)에서 독립 사건과 후속 사건을 구분해 확인할 수 있다. 현재 미식전 10개·후유키 9개·나비저택 7개의 독립 사건을 포함한다. 원안 상황·문장 재요청·고정 수치·수정 전후·채택 판단과 신규 분기 모의 대조를 함께 보존한다. 원본 보관은 바이트 기준이며 모델 출력의 개발 해설·번역된 key·누락 효과를 활성 데이터로 그대로 옮기지 않는다.

카라쿠라와 아메스트리스 확장에서는 각각 독립6사건·4카드, 독립7사건·6카드를 더했다. 카라쿠라는 독립9개·전체14개, 아메스트리스는 독립10개·전체14개다. 변경 전 바이트와 해시, 원안 수치, 문장별 수정 이유, 모델 유지 권고를 보존했다. 신규13사건·분기69가지 대조와 compile-16은 validation에 있다.

아비도스·학원도시 확장에서 각각 독립6사건·5카드와 독립6사건·6카드를 추가했다. 두 머리는 독립10개·전체12개다. 오류가 있던 집필·재집필과 항목별 수정·원본 바이트·채택 해시·모델 역검토를 보존했다. validation의 probe-04는12독립 사건·69분기,compile-17은 스크립트 컴파일이며 실제 게임·맵 검증은 아니다.

미타키하라·아인크라드·액셀은 독립 사건 6·5·5개와 카드 6·5·5장을 추가해 각각 독립 10개가 되었다. 원본 바이트와 해시·집필 원문·문장별 제외 이유·역검토·채택을 보존했다. probe-05는 독립 사건 16개·분기 90가지, compile-18은 스크립트 컴파일이다. 실제 게임과 맵 검증은 아니다.
