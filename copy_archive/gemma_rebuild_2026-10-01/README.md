# 사건·카드 재제작 보관 안내

이 폴더는 활성 콘텐츠가 아니다. 기존 콘텐츠의 원본, 생성 요청, Gemma 응답과 채택 전후 검토본을 보존한다. 사용자 지시에 따라 폐기한 내용도 삭제하지 않는다.

- `before_rewrite/`. main `067d5d68cc9db8acf15c94b09d73d99c497c2eb8` 기준 교체 전 11개 파일. manifest의 SHA-256은 보관 파일의 실제 바이트 기준이다.
- `requests/`. 모델에 전달한 질문·정의·설정 범위. 재검토 입력도 포함한다.
- `drafts/`. 원본 응답, 요청, 모델 옵션과 소요 시간. 검토를 통과하지 않은 내용을 포함한다.
- `reviews/`. Gemma의 평가 원문. 모델 판정을 검증 완료로 취급하지 않는다.
- `revisions/`. Codex 수정본, 수치 계획 및 추가 수정 이전의 원문. 일회성 결합 스크립트는 당시 작업 과정을 보존하는 용도다.

실제로 로드하는 데이터는 `content/roguelite/*.json`과 그것에서 생성한 `Data/Data_PrototypeCatalog.j`이다. Import.j는 이 보관 폴더를 참조하지 않는다. 새 맵 파일은 만들지 않았다.
