# 개인 사냥 프로토타입

이번 작업은 소스만 변경한다. `.w3x` 제작·복사·패키징은 수행하지 않는다.

## 플레이 흐름

1. 영웅 선택 후 마을에서 첫 무기 계승을 진행한다. 기존 ID10 → ID3 경로가 공격력 1의 T1 무기를 공격력 100의 T2 무기로 바꾼다. T1·공격력 100 미만·마을 밖·사망 상태에서는 출발할 수 없다.
2. 도감에서 발견한 머리 카드 0~1장을 선택하고 출발 준비를 누른다. 첫 플레이는 머리 카드 없이 출발한다. 출발은 현재 참가자 전원이 준비했을 때 진행한다.
3. 플레이어 슬롯 1~4에 각각 사냥 구역 1~4를 배정한다. 구역 5~6 중 빈 곳을 보스용으로 예약한다. 사용 중인 구역을 덮어쓰지 않는다.
4. 최대 600초 동안 개인 사냥과 사건을 진행한다. 행동력은 각자 10이다. 팀 투표와 상점은 이번 진행에서 사용하지 않는다.
5. 행동력을 모두 쓰고 진행 중인 사건을 마쳤다면 화면 상단 준비 완료 버튼을 누를 수 있다. 남은 시간 1초당 1골드를 한 번 지급하고 해당 공간을 정지한다.
6. 전원 준비 완료 또는 600초 경과 시 사냥 몬스터를 제거하고 기존 대표 보스 전투에 합류한다. 진행 중이며 행동력을 이미 지불한 사건은 비용 없는 두 번째 분기로 마무리한다. 아직 사건 후보만 보고 있었다면 강제로 행동력을 소비하지 않는다.
7. 보스 전투 후 마을로 돌아온다. 다음 원정에서 개인 카드·각성·필드 조건·골드·처치 수·사건 소비 기록을 초기화한다. 기존 영구 성장과 도감 발견 기록은 유지한다.

## 테스트용 수치

기존 장기 밸런스를 이어받는 확정안이 아니다. 공격력 100 출발을 기준으로 기본 작동과 재미를 확인하기 위한 값이다.

| 항목 | 초기값 |
| --- | --- |
| 개인 사냥 제한 시간 | 공통 최대 600초, 사건 선택 중에도 흐른다. |
| 행동력 | 개인별 10, 사건 선택 시 1 소비 |
| 기본 몬스터 | 근접 공격, 체력 300, 방어력 0, 이동속도 380 |
| 기본 밀도 | 개인별 동시 4마리, 사건으로 1~10마리 |
| 적 단계 | 1~5, 단계당 체력 +30%, 근접 피해 +25% |
| 근접 공격 | 0.5초 빨간색 예고, 기본 최대 생명력 4% 피해, 공격 후 1초 대기 |
| 처치 보상 | 기본 10골드, 카드 수급 효과만 추가 가능 |
| 사냥 사망 | 15초 후 생명력 100% 부활, 골드·행동력 패널티 없음 |
| 사건 최소 간격 | 실제 사냥 시간 20초 |
| 사건 발생 조건 | 지난 사건 뒤 12처치, 사냥 시간 45초, 마지막 처치 후 25초 중 하나 |
| 사건 후보 | 기본 2개, 카드 효과로 최대 4개 |
| 사건 리롤 | 500골드, 이후 100골드씩 증가. 새 후보 화면은 500골드부터 시작 |
| 후보/분기 선택 제한 | 각각 45초. 후보 만료는 사냥 재개, 분기 만료는 무료 선택 |
| 결과 확인 | 8초 후 사냥 재개, 확인 버튼으로 즉시 재개 가능 |
| 머리 카드 | 학원도시·페나코니·홍마관, 원정 중 최대 3장, 장당 피해 +5% |
| 머리 발견 가중치 | 미보유 머리 발견 사건 20, 열린 지역 사건 3, 공통 사건 1 |
| 카드 등급 가중치 | 노말 60, 레어 30, 에픽 9, 프리즘 1. 실제 확률은 현재 획득 가능한 재고에 따라 달라진다. |
| 대표 보스 | 기존 패턴 재사용, 시험 체력 12,000 × 참가 인원, 제한 360초 |

행동력 0은 **신규 사건만 중지**한다. 사냥·골드 획득·카드 각성은 계속된다. 사망 시간·사건 선택 시간·준비 완료 대기 시간은 개인 사냥 시간이나 무피격 각성 시간에 포함하지 않는다.

## 머리 카드·성장 카드·사건

- 머리 카드는 지역을 열고 관련 사건과 카드가 추첨 대상에 들어오게 한다. 시작 머리 카드는 공유 상태로 동기화된 도감에서만 선택할 수 있다.
- 성장 카드는 24종이다. 공통 6종과 지역별 6종으로, 희귀도·지역/효과 키워드·캐릭터·효과 이름·능력치를 갖는다.
- 피해 증가, 방어력 관통, 처치 골드, 받는 피해 감소, 고정 신속, 사건 후보 추가, 보유 골드 기반 피해 효과를 시험한다. 일반 피해 증가는 합산한다. 관통은 기존 전투의 60% 상한, 카드 받는 피해 감소도 합산 후 60% 상한을 적용한다.
- 카드 각성은 일부 카드만 가진다. 획득 이후 처치, 실제 제거한 몬스터 체력, 연속 무피격 사냥 시간을 쌓아 피해 +25%를 추가한다. 초과 피해는 누적하지 않는다. 보호막으로 받은 공격도 무피격 조건을 끊는다. 각성 시 텍스트와 기존 부활 이펙트로 알린다.
- 발견한 머리·성장 카드·각성 기록을 기존 Stash 저장 경로에 기록한다. 현재 대기실에서는 머리 도감만 선택 UI로 제공한다. 서버 저장 성공과 재접속 복구는 실게임 검증이 필요하다.
- 사건은 72개의 식별자를 사용한다. 머리 발견 12개, 지역 사건 36개, 공통 사건 24개다. **서로 다른 이름·지역 이야기이며, 효과는 아래 8개 처리 형태를 재사용하는 시험 콘텐츠다.** 72종의 독립적인 전투·기믹을 만든 것은 아니다.

| 사건 형태 | 첫 번째 분기 | 두 번째 분기 |
| --- | --- | --- |
| 지역 발견 | 머리 카드 획득, 관련 풀 개방 | 100골드 |
| 카드/자원 | 무작위 카드 1장 | 150골드 |
| 밀도 조절 | 몬스터 +2, 카드 1장 | 몬스터 -1, 100골드 |
| 단계 조절 | 적 단계 +1, 250골드 | 적 단계 -1 |
| 주사위 내기 | 200골드 소비, 주사위 4~6에 카드 2장 | 80골드 |
| 성장 단서 | 무작위 카드 1장 | 150골드 |
| 위험한 힘/회복 | 적 단계 +1, 피해 +15% | 생명력 100% 회복 |
| 교환 또는 보급 | 교환 사건은 300골드로 카드 2장, 보급 사건은 생명력 물약 +2 | 교환은 100골드, 보급은 150골드 |

서사와 보상 분기는 전면 밸런스 확정 전에 교체할 수 있도록 데이터와 처리 코드를 나눴다. 지급 가능한 카드가 모두 소진되면 카드 한 장당 100골드로 대체한다. 단계·밀도 상한 때문에 위험이 늘어나지 않는 고보상 분기는 비활성화한다.

사건 후보를 보기만 하면 소비하지 않는다. 사건을 선택한 순간 파티 전체에서 해당 식별자를 제외한다. 같은 후보를 보던 다른 플레이어의 화면을 새로 추첨하고 후보 버전을 갱신한다. 오래된 원정·화면·후보 버전의 요청, 중복 분기 확정, 준비 완료 보너스의 반복 지급을 거부한다.

## 검증 범위

- 정적 검사와 로컬 UI 호출 경계 검사.
- 실제 JASS 함수를 모의 네이티브 환경에서 실행하는 기존 회귀 검사 및 개인 사냥 검사.
- 기존 배치 스크립트와 현재 Import.j를 결합한 JassHelper/PJass 스크립트 컴파일. 기존 환경이 무시하는 24개 오류는 그대로 남는다.
- 실제 워크래프트 플레이·화면 렌더링·멀티플레이·네트워크 저장은 미실시.
- 맵 제작·패키징·배포는 미실시.
