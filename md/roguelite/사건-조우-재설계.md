# 사건·조우 재설계

## 바꾸는 경험

기존 사건은 캐릭터 이름 아래 두 수치 보상을 나열했다. 이번에는 상황을 먼저 보여 주고,
행동을 선택하면 자원 변화와 짧은 결과 문장을 함께 보여 준다. 등장인물의 이름으로
보상의 이유를 대신하지 않는다. 모든 사건에 억지로 손해를 붙이지 않고 보급이나 행운도 섞는다.

개인 사건은 내 골드·물약·카드·원정 각인만 바꾼다. 파티 전투를 바꾸는 조우는 전원이 투표한다.
현재 시험 원정의 경로 길이, 60초 보상 선택, 사건 진입 후 40초, 조우 투표 40초는 유지한다.
개인 결과는 최대 12초간 읽고 `계속`으로 닫을 수 있다. 시간 초과는 비용 없는 떠나기다.

## 참고 구조

- [위험한 먹이 주기](https://honkai-star-rail.fandom.com/wiki/Dangerous_Feeding)는 부정적 기물을 처리하는 선택을 전투 및 보상과 연결한다. 현재 자원/상태가 사건의 가치를 바꾸는 구조를 참고했다.
- [닐디스·멧돼지](https://game8.co/games/Honkai-Star-Rail/archives/477636)는 보상을 노릴수록 전투 위험을 감수하게 한다. 이번 금고는 멀티 대기를 늘리는 반복 도전 대신 한 번의 명시적 확률 선택으로 축소했다.
- [은하 장사꾼 (1)](https://honkai-star-rail.fandom.com/wiki/Cosmic_Merchant_%28I%29)은 대가와 구매 결과를 연결한다. 차분화 우주에서는 3.1에 제거된 과거 사례이며, 현행 콘텐츠로 간주하지 않고 거래 설계 참고로만 사용했다.

위 사건의 문장이나 보상을 복제하지 않는다. 아래 이름·서술·수치는 우리 맵용 시험안이다.

## 개인 사건 9종

각 사건에는 비용 없는 `떠나기`가 있다. 수치는 전부 이번 원정에만 적용한다.

| 등급/사건 | 상황 | 행동 A | 행동 B |
|---|---|---|---|
| 일반 · 잊힌 야영지 | 철수한 야영지에 약상자와 흩어진 귀중품이 남았다. | 약상자를 챙긴다. 회복 물약 +1회 | 귀중품을 모은다. +80골드 |
| 일반 · 노점의 밀봉 상자 | 상인이 훈련 기록과 전투 물약을 판다. | 기록 상자를 산다. 100골드 → 일반 카드 1장 | 물약을 산다. 50골드 → 최종 대미지 물약 +1회 |
| 일반 · 바퀴가 부서진 수레 | 다친 상인이 수레를 지키고 있다. | 약을 건넨다. 회복 물약 1회 → +200골드 | 수레를 밀어준다. +60골드 |
| 일반 · 금이 간 각인석 | 힘과 저주가 같은 균열에서 새어 나온다. | 힘을 받아들인다. 표시된 일반 각인 최대 +2, 표시된 감소 각인 +1 | 파편을 판다. +80골드 |
| 희귀 · 기억을 사는 수집가 | 수집가가 내가 가진 전투 기록 하나를 지목한다. | 기록을 교환한다. 표시된 일반 카드 반납 → 희귀 카드 1장 | 기록을 판다. 같은 카드 반납 → +250골드 |
| 희귀 · 봉인된 금고 | 금고 앞 동전 주머니와 유료 해제 장치가 있다. | 주머니만 챙긴다. +100골드 | 금고를 연다. 100골드 지불, 50%로 400골드 획득 / 50%로 빈 금고 |
| 희귀 · 침묵의 정화샘 | 금속을 녹이는 물이 몸에 붙은 저주도 씻어 낸다. | 정화한다. 150골드 → 표시된 감소 각인의 원정 획득분 전부 제거 | 약수를 담는다. 회복 물약 +2회 |
| 희귀 · 각인사의 작업대 | 각인사가 손님을 기다리며 작업대를 펼쳤다. | 각인을 새긴다. 150골드 → 표시된 일반 각인 +1, 감소 각인 없음 | 작업대를 정리한다. +100골드 |
| 영웅 · 멈춰 선 보급 열차 | 주인 잃은 열차에서 온전한 전투 기록과 보급품을 발견한다. | 기록을 챙긴다. 희귀 카드 2장 | 보급품을 챙긴다. +500골드, 세 물약 각각 +1회 |

규칙.

- 카드 교환은 반납할 카드 이름을 미리 표시한다. 일반 카드 보유자에게만 수집가가 등장한다.
- 정화는 장비 각인을 지우지 않는다. 원정에서 얻은 감소 각인이 있을 때만 정화샘이 등장한다.
- 현재 짧은 시험 경로는 개인 성장 선택이 한 번뿐이어서 정화샘의 등장 조건을 자연스럽게 충족하지 못한다. 조건부 사건으로 구현했으며, 이후 성장 선택이 반복되는 경로에서 활용한다.
- 일반 각인은 3레벨 미만을 후보로 삼고 실제 증가량을 표시한다. 감소 각인도 효과 상한에 이른 종류는 대가 후보에서 제외한다.
- 거래의 골드·카드·물약 조건은 버튼과 동기화 수신부에서 모두 확인한다. 불충족 시 차감/사건 종료 없이 거부한다.
- 무작위 카드 재고가 없으면 해당 구매/교환 버튼을 막는다. 보급 열차의 기록 선택은 희귀 카드 2장이 남아 있을 때만 가능하다.
- 카드가 반납되어도 기존 등장 기록은 유지한다. 같은 원정에서 팔고 다시 얻는 반복 거래를 막는다.
- 물약 추가 충전은 기존 바이바인 카드의 +1 규칙을 따른다. 물약 반납에는 이 보너스를 적용하지 않는다.
- 사건별 파티 내 중복 방지, 후보 예약, 미선택 예약 해제, 리롤 및 등급 소진 시 지원금 규칙을 유지한다.

## 파티 조우 3종

조우는 후보를 공통 난수로 한 번 정한다. 전투 선택은 과반수일 때만 통과하며 동률과 시간 초과는 우회 쪽으로 처리한다.
전투 보상은 승리한 참가자 각각에게 지급한다. 기본 전투 보상/승리 재료/실패 라이프 판정은 유지한다.

| 조우 | 전투 선택 | 안전한 선택 |
|---|---|---|
| 무너진 봉쇄선 | 빈틈으로 돌파. 일반 적 체력 45만 × 인원, 제한 120초, 기본 승리 보상 | 보급로로 우회. 전투 생략, 무작위 물약 +1회 후 개인 성장 |
| 마물의 식량 창고 | 창고 습격. 일반 적 체력 55만 × 인원, 제한 120초, 승리 골드 추가 +100 | 외곽만 수색. 전투 생략, 각자 +50골드 후 개인 성장 |
| 길목의 결투자 | 도전 수락. 일반 적 체력 45만 × 인원, 제한 90초, 승리 시 일반 카드 추가 1장 | 길을 비켜 간다. 전투 생략, 각자 +60골드 후 개인 성장 |

결투자의 추가 카드 재고 소진 시 기존 일반 등급 지원금 150골드로 대체한다.
조우의 체력/시간 조건은 일반전에만 적용하고 마지막 보스에는 적용하지 않는다.

## UI와 동기화

입장 전에는 사건 제목과 한 줄 상황을 보여 준다. 사건 안에서는 `첫 번째 보상` 대신
`약을 건넨다`, `기록을 교환한다` 같은 행동을 쓰고, 비용·획득·확률·불가 이유를 카드 본문에 표시한다.
선택 후 결과 문장과 실제 지급 내역을 보여 준다. 결과를 다시 클릭해도 보상을 재실행하지 않는다.

UI는 조회와 기존 ExpCmd 송신만 수행한다. 추첨, 비용 차감, 효과 적용,
조우 결정은 공통 게임 로직에서 처리한다. 결과 진입 시 후보 버전을 올려 중복 패킷을 거부한다.

## 보존과 검증

교체 전 진행/UI 스크립트는 `copy_archive/expedition-events-before-rework/`에 보관한다.
해당 파일은 Import.j에 넣지 않는다. 맵 파일은 생성하지 않는다.
각 사건의 지급/차감, 부족 조건, 만료, 중복 요청, 카드 효과 회수와 조우 전투 조건을
모의 실행하고 기존 UI/동기화 검사 및 스크립트 컴파일을 수행한다.
실제 멀티 입력과 텍스트 배치는 별도의 게임 확인 대상이다.

검증 기록.

- 진행 33개, 사건·조우 12개, 공격력·물약 10개, UI 15개, 시작 입력 9개 시나리오 그룹 및 캐릭터 선택 진단 검사를 통과했다. 모두 실제 JASS 함수를 사용하는 모의 실행 또는 정적 검사다.
- 로컬 UI의 14개 진입점에서 49개 함수 호출 경로를 검사했다. 난수·자원 변경·핸들 생성·미등록 호출의 음성 대조 검사도 통과했다.
- JassHelper의 `--scriptonly`와 pjass 검사에 성공했다. 기존 JAPI 환경의 `24 errors ignored` 표시는 유지되며, 게임 실행 성공을 의미하지 않는다.
- 실제 Warcraft 실행, 실제 멀티 재현, 인게임 시각 검사는 수행하지 않았다. 맵 파일은 생성하거나 수정하지 않았다.
