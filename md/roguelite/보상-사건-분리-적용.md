# 기본 보상과 추가 사건 분리 적용

2026-09-20의 최신 기획과 이후 사용자의 시간 유지 답변을 기준으로 한다.
기획 원문은 `워크래프트 로그라이트 기획 보완` 작업의 `전투보상_추가이벤트_분리설정.md`다.
기본 보상 뒤 사건을 추가하고, 팀 전용 사건이 있을 때는 개인 사건을 생략한다는 두 변경을 확인했다.

## 현재 시험 경로에서 바뀌는 흐름

일반 조우 → 전투 또는 우회 → 기본 보상 선택 → 추가 개인 사건 → 상점 → 최종 보스 → 종료.

- 기본 보상은 스탯 5포인트 / 각인 묶음 / 즉시 랜덤 보상 중 하나다.
- 어느 기본 보상을 골라도 지급·능력치 재계산을 먼저 마치고 추가 사건을 새로 추첨한다.
- 사건에서 거래를 거절하거나 실패해도 기본 보상은 회수하지 않는다. 사건 선택에 명시된 거래 비용만 적용한다.
- 기본 보상 화면에는 미래 사건의 이름·등급을 표시하지 않는다. 즉시 보상과 사건의 등급을 별도로 추첨한다.
- 기본 보상으로 새로 얻은 카드·각인 상태를 사건 조건에 반영한다. 각인 보상을 받은 직후 정화샘이, 카드 보상을 받은 직후 수집가가 등장할 수 있다.
- 먼저 고른 플레이어는 즉시 자기 사건을 진행한다. 다른 플레이어의 선택은 닫지 않으며 모두 사건까지 끝나야 다음 구역으로 한 번 이동한다.
- 비전투 우회와 라이프가 남은 일반전 실패도 같은 순서다. 시작·상점·최종 보스 종료·라이프 소진에는 새 개인 사건을 붙이지 않는다.

## 시작 카드 통합

2026-09-20 21:32에 수정된 통합 기획의 시작 선택을 반영한다.
시작 화면은 스탯 10포인트 / 무작위 고정 치명 또는 신속 +200 / 무작위 일반 각인 +2 /
카드 / 골드 +200의 다섯 자리다. 사용자가 앞서 요청한 골드 마지막 배치를 유지한다.

카드 자리는 화면 생성 시 다음 셋 중 하나만 제시한다.

| 유형 | 제시 확률 | 카드 이름 공개 시점 |
|---|---|---|
| 무작위 노말 2장 | 1/3 | 선택 후 |
| 미리 공개된 노말 1장 | 1/3 | 시작 화면 생성 시 |
| 무작위 레어 1장 | 1/3 | 선택 후 |

UI는 각 유형의 제시 확률을 33%로 표시한다. 실제 추첨은 `GetRandomInt(1, 3)`이며 별도의 1% 결과는 없다.
기존 별도 레어 카드 자리를 통합하고 선택 영역을 5개 너비로 재배치했다.
공개 노말 카드는 미선택이어도 등장 기록을 유지하며, 무작위 카드 이름은 선택 전 추첨·공개하지 않는다.
시작은 60초, 리롤 없음이며 기본 시작 포인트 5점은 별도로 유지한다.

## 즉시 랜덤 보상

등급은 노말 55 / 레어 35 / 에픽 9.5 / 프리즘 0.5%다. 같은 등급의 유효 항목끼리 동일 확률로 추첨한다.
행운은 기존 `L+1회 중 최고 등급` 규칙을 두 추첨에 각각 적용한다.

| 보상 등급 | 현재 지급 가능한 항목 |
|---|---|
| 노말 | 150골드 / 노말 카드 1장 / 고정 치명 75 / 고정 신속 75 / 회복 물약 2회 / 기존 물약 한 종류 3회 |
| 레어 | 250골드 / 레어 카드 1장 / 노말 카드 2장 / 고정 치명 150 / 고정 신속 150 / 세 물약 각각 2회 |
| 에픽 | 500골드 / 레어 카드 2장 / 스탯 15포인트 / 고정 치명 250 / 고정 신속 250 |
| 프리즘 | 고정 치명·신속 각각 300 / 1,200골드 |

기획표 23항목 중 현재 시험 경로에서 가능한 항목은 19개다.
희귀·전설 카드 풀이 아직 없어 해당 카드를 요구하는 3항목을 제외한다.
행운 +1도 뒤에 기본 성장 기회가 2회 이상 남아야 하는 조건을 현재 짧은 경로에서 충족하지 못해 제외한다.
지원하지 않는 카드를 다른 등급 카드로 바꾸어 지급하지 않는다. 같은 보상 등급의 나머지 유효 항목을 추첨한다.

카드 이름은 선택 후 공개한다. 후보 생성 시 개인 미등장 카드를 비공개 예약하고,
리롤·다른 보상 선택·이탈·화면 종료 때 예약만 반환한다. 이때 등장 기록은 추가하지 않는다.
실제로 받은 카드만 등장·소유 기록에 남긴다. 다른 카드 추첨도 비공개 예약을 제외해 충돌을 막는다.
현재 보유하거나 이미 등장한 카드, 상점 전용 카드도 일반 보상 풀에 다시 넣지 않는다.

15포인트는 총 40포인트 한도 안에서 전량 지급할 수 있을 때만 등장한다.
기본 스탯 자리는 이미 40포인트면 100골드로 표시한다. 40 미만에서는 기존 5포인트 및 초과분 포인트당 20골드 규칙을 유지한다.
무작위 물약 3회는 한 종류의 충전 묶음이다. 세 종류 각각 2회와 다르며 바이바인의 기존 추가 충전 규칙을 적용한다.

## 리롤과 시간

- 기본 보상 리롤만 허용한다. 스탯 자리는 유지하고 각인과 즉시 보상을 함께 다시 만든다.
- 비용은 100 → 200 → 300골드이며 남은 시간을 늘리지 않는다.
- 사건 진입 뒤에는 기본 보상을 다시 선택하거나 리롤할 수 없다. 사건에 별도 리롤은 없다.
- 사용자가 재확인한 시간은 기본 보상 60초 / 개인 사건 40초 / 마지막 이동 6초다. 시작·팀 투표·상점의 기존 시간도 유지한다.
- 기본 보상 시간 초과는 기존 스탯 자동 지급 뒤 사건으로 이어진다.
- 사건 시간 초과는 무료·무위험 즉시 보상을 우선하며, 유료 거래만 있으면 떠난다. 결과 확인은 최대 12초이고 일찍 계속할 수 있다.
- 사건 풀이 소진되면 같은 등급 지원금 화면을 보여 준다. 기본 보상을 유지하며 사건 소모 기록은 새로 추가하지 않는다.

## 본편과의 적용 범위

본편 기획의 갈림길 6·13·20번, 중간보스 8·15번은 개인 사건 제외 대상으로 판정한다.
현재 시험 경로에는 그 구역들의 보상 후 팀 전용 사건 진행기가 없다. 제외 조건만 검증했으며,
팀 전용 사건 내용이나 23칸 본편 진행을 구현했다고 간주하지 않는다.
본편의 개인 사건 80종·카드 100종·선택 수를 늘리는 미구현 카드 효과도 이번 순서 변경에 포함하지 않는다.
현재 구현된 개인 사건 9종과 카드 12종을 사용한다.

## 동기화와 검증

후보 생성·카드 예약·지급·사건 추첨은 공통 게임 로직에서만 실행한다. UI는 조회와 기존 ExpCmd 송신만 한다.
기본 보상 확정 시 후보 버전을 올려 이전 화면의 중복 요청이 새 사건의 클릭으로 처리되지 않게 한다.

진행 35개, 사건 12개, 보상 분리 13개, 공격력·물약 10개, UI 18개, 시작 입력 9개 그룹과
캐릭터 선택 진단 검사를 통과했다. 로컬 UI 정적 호출 경로 및 금지 동작 대조 검사도 통과했다.
JassHelper `--scriptonly`와 pjass는 성공했으며 기존 JAPI 설정의 `24 errors ignored` 표시가 유지된다.
실제 Warcraft 멀티플레이 및 인게임 시각 검사는 수행하지 않았다.
