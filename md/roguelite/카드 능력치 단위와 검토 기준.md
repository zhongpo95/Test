# 카드 능력치 단위와 검토 기준

모델에 값을 전달할 때 고정 수치와 퍼센트를 구분한다. 숫자가 작거나 크다는 사실만으로 밸런스가 검증되지는 않는다. 아래는 현재 소스의 계산이며 실제 Warcraft에서 체감·성능을 검증한 결과가 아니다.

## 신속과 속도

`swift`는 고정 신속 수치다. `System/StatsSetting.j`의 행동 속도 기여는 신속 ÷45이고, `System/Cooldown.j`의 쿨타임 감소 기여는 신속 ÷46이다. 이동 배율에도 신속 ÷45를 합산한다. 행동·이동은 다른 버프와 상한을 공유하며 정수 변환이 있고, 쿨타임은 신속 감소 75% 상한과 보석 배율을 적용한다.

| 고정 신속 | 행동 속도 기여 | 신속 쿨타임 감소 기여 |
| --- | --- | --- |
| 3 | 약 0.067% | 약 0.065%p |
| 5 | 약 0.111% | 약 0.109%p |
| 6 | 약 0.133% | 약 0.130%p |
| 90 | 2% | 약 1.96%p |
| 180 | 4% | 약 3.91%p |
| 270 | 6% | 약 5.87%p |

최근 카드의 윈리 3·이즈미의 흐름 5·탄지로 6은 고정 단위를 고려할 때 선택 가치가 지나치게 낮았다. 각각 90·180·180으로 수정했다. 3·5·6을 그대로 퍼센트로 바꾸거나 일괄 ×45하지는 않았다. 신속이 여러 효과를 주는 점과 다른 후보의 90~270 구간을 고려한 제작 후보이며 기존 카드의 수치를 함께 상향하지 않는다. 원안과 이유는 `copy_archive/gemma_rebuild_2026-10-01/revisions/swift-unit-correction-01.json`에 남겼다.

`action_speed`, `move_speed`, `charge_speed`는 각 이름의 속도 퍼센트다. 신속처럼 재사용 시간·이동·행동을 모두 바꾸는 값이 아니다. 사건에서 새 기술이나 돌진을 준다고 설명하지 않는다. 콘텐츠 검사기는 절댓값 45 미만의 0이 아닌 고정 신속을 검토 경고로 표시한다. 의도한 작은 값까지 자동 폐기하지 않으며 검토자가 단위와 이유를 확인한다.

## 그 외 능력치

| 키 | 단위·적용 |
| --- | --- |
| attack_percent | 영구 무기 공격력 계산 뒤 런 공격력 증가 %를 합산하여 적용. |
| damage_percent | 대미지 증가 %. 같은 항목 안에서 합산. |
| final_damage_percent | 최종 대미지 증가 %. 대미지 증가와 별도 배율. |
| boss_damage_percent / normal_damage_percent | 해당 대상 피해 %. 각각 대상 조건에 맞을 때 별도 배율. |
| crit_chance | 치명타 확률 %p. 영구 치명 점수가 아닌 확률로 직접 합산. |
| crit_damage | 치명타 피해 배율의 추가 %p. 비치명 공격에는 적용되지 않음. |
| penetration | 방어력 관통 %. 방어력에 적용하며 방어력 0의 적에게 직접 피해 보너스를 주지 않음. |
| max_health_percent / damage_reduction | 최대 체력 증가 % / 받는 피해 감소 %. 체력 지불 비용과 구분. |
| leech | 실제로 가한 피해에서 흡수 저장량을 만드는 %. 초당 최대 체력 회복률과 구분. |
| regeneration | 초당 최대 체력 비례 재생 %. 흡수와 합산하여 10%/초 한도. |
| kill_gold | 처치당 고정 추가 골드. 골드 획득 %가 아님. |
| event_choices | 사건 후보 추가 개수. 정수이며 총 최대 4개. 행동 선택 개수·행동력 추가와 구분. |
| moving_damage | 추가 이동 속도에 따른 조건부 대미지 %. 이동 중이라는 판정만으로 활성화되지 않음. |
| directional_damage / nondirectional_damage | 헤드·백 적중 / 비방향 공격의 조건부 대미지 %. |
| shielded_damage / charge_damage / healthy_damage | 보호막 유지 / 차지 공격 / 체력 65% 이상일 때의 조건부 대미지 %. |

조건부 효과는 대응 조건이 없는 캐릭터에게 같은 가치를 주지 않는다. 각성 효과는 조건 달성 뒤 기본 효과에 더해진다. 체력 재생·흡수·물약의 차이는 [회복 비교 기준](흡수와%20재생%20카드의%20비교%20기준.md)에 적었다. 모델에게는 값뿐 아니라 이 단위와 조건을 함께 전달한다.

## 같은 효과의 낮은 카드와 다른 성장 목적

수치 성분만 비교하는 검사는 가격·확률·필드 부담·개인 후속 접근과 각성 시간을 포함하지 않는다. 경고 후보를 찾는 데만 사용한다. 이번 3장은 각성 차이 없이 성장 축까지 같아, 최대 체력·차지 준비·처치 수입으로 구분했다.

추가 최대 체력은 즉시 치유가 아니다. 현재 체력 7000은 기본 최대 체력 10000에서는 65% 이상이지만, 최대 체력 10800에서는 약 64.8%라서 고체력 피해 조건에 미달한다. 물약과 체력 관리를 함께 고려해야 한다. 스파클의 차지 12%는 Arcana_ChargeSpeed를 사용하는 준비 구간에만 적용한다. 다른 속도가 없을 때 기존 행동 8%의 준비 배율 1.08보다 1.12로 높지만 일반 행동에는 기존 1.08 대신 1.00이며 치명타 피해도 1%p 낮다. 스킬 전체 DPS와 실제 프레임을 검증한 수치가 아니다.
