# 머리별 사건 확장 계획

사용자가 같은 머리를 고른 원정에서도 다양한 사건을 만나도록 관련 사건을 많이 늘려 달라고 요청했다. 기존 머리 13종의 독립 사건을 중심으로 확장하며, 독립 사건 10개 안팎을 첫 확장의 기준으로 사용한다. 개수 상한을 두지 않고 약한 원안은 이유와 재검토 조건을 남겨 제외한다.

확장 시작 시점의 91개 사건에는 독립 52개와 개인 후속 39개가 포함됐다. 공통 여행길은 독립 7개·후속 6개이고, 시작 시 머리별 독립 사건은 아래와 같다. 후속은 이전 행동 조건을 만족해야 하므로 처음 만날 수 있는 독립 사건 개수와 구분한다.

위 소재는 조사 방향이며 아직 작성·원작 확인·구현된 사건이라고 주장하지 않는다. 나비저택과 미식전처럼 독립 사건이 하나인 머리부터 채운다. 같은 머리의 여러 사건이 같은 카드만 반복 지급하는지, 이미 가진 카드의 100골드 교환 때문에 선택 의미가 달라지는지도 함께 확인한다.

각 묶음은 공식 근거 확인, Gemma 집필, 별도 내용·수치·구현 대조, 원문과 폐기 이유 보존, 생성 데이터와 모의 검사·스크립트 컴파일, Draft PR 전달의 순서로 처리한다. 머리 시스템과 사건 방문 규칙은 유지하며 맵은 만들지 않는다. 카드 등급 중복 검토는 확장 뒤 이어갈 항목으로 남긴다.

## 확장 반영 기록

미식전의 작은 방 정리·번진 채집 지도·접힌 모임 안내장을 독립 사건으로 추가했다. 독립 사건은 1개에서 4개, 관련 사건 전체는 3개에서 6개, 카드는 6장에서 9장으로 늘었다. 기존 식사와 두 후속, 입문 카드·머리 효과는 유지한다. 더 많은 독립 사건을 이어서 검토한다. [집필 원문](../../copy_archive/gemma_rebuild_2026-10-01/drafts/gourmet-expansion-04.json)·[수정 기록](../../copy_archive/gemma_rebuild_2026-10-01/revisions/gourmet-expansion-curation-04.json)·[검토와 채택 판단](../../copy_archive/gemma_rebuild_2026-10-01/revisions/gourmet-expansion-decision-04.json)을 보존했다.

나비저택에는 지워진 병 이름·마르지 않은 천·전령 안내·낮의 소리·겹친 흔적·벌어진 보급낭의 독립 사건 6개를 추가했다. 독립 1개에서 7개, 전체 3개에서 9개, 카드 6장에서 12장으로 늘었다. 박 납품·표식 철거·문병객 세 원안은 선택 구조가 겹쳐 제외했다. [원문과 미채택 이유](../../copy_archive/gemma_rebuild_2026-10-01/revisions/butterfly-expansion-rejected-04.json), [수정·참조 대조](../../copy_archive/gemma_rebuild_2026-10-01/revisions/butterfly-expansion-curation-05.json), [최종 후보와 검토 판단](../../copy_archive/gemma_rebuild_2026-10-01/revisions/butterfly-expansion-decision-06.json)을 보존한다.

두 머리의 새 독립 사건 9개, 분기 모의 실행 55가지를 확인했다. 머리 미소지 시 제외, 이전 기록 없이 등장, 행동력 1회, 지정 카드와 중복 100골드, 비용·물약·필드 변화, 65/66·70/71 확률 경계, 빈 골드와 필드 상한에서 유효 선택을 대조했다. 생성 문서 일치와 기존 통합 검사, 스크립트 전용 컴파일도 통과했다. 실제 Warcraft·멀티플레이·화면·재미·플레이 밸런스는 미검증이며 맵은 생성하지 않았다. 전체 후보는 머리 13종·카드 124장·사건 100개이고 독립 61개·후속 39개다.

미식전에는 농사·의상 배달·시각이 다른 증언·상점 경계·갈라진 배달길·연습 자리의 독립 사건 6개를 더했다. 현재 독립 10개·전체 12개·카드 14장이다. [원안 8개의 판단](../../copy_archive/gemma_rebuild_2026-10-01/revisions/gourmet-pitch-selection-05.json), [문장 수정](../../copy_archive/gemma_rebuild_2026-10-01/revisions/gourmet-expansion-curation-06.json), [채택과 모델 제안의 판단](../../copy_archive/gemma_rebuild_2026-10-01/revisions/gourmet-expansion-decision-06.json)을 보존한다.

후유키에는 궁도부 상자·빠진 연락·신지의 협력 제안·잠깐의 외출·목격담·시로와 아처의 다른 이상으로 독립 사건 6개를 추가했다. 독립 3개에서 9개, 전체 4개에서 10개, 카드 8장에서 13장으로 늘었다. 지도 원안은 마지막 사건과 행동 구성이 겹쳐 제외했다. [재요청 이유](../../copy_archive/gemma_rebuild_2026-10-01/revisions/fuyuki-text-rejection-07.json), [제외와 수정](../../copy_archive/gemma_rebuild_2026-10-01/revisions/fuyuki-expansion-curation-08.json), [채택 판단](../../copy_archive/gemma_rebuild_2026-10-01/revisions/fuyuki-expansion-decision-08.json)을 보존한다.

이번 추가 독립 12개·분기 모의 실행 62가지를 확인했다. 60/61·70/71 경계, 실패 시 비용과 적 수 유지, 지정 카드·중복 100골드, 행동력 1회, 머리 미소지 제외와 필드 상한·빈 골드에서 남는 선택을 대조했다. 콘텐츠 21그룹·생성 일치·스크립트 컴파일도 통과했다. [검사](../../copy_archive/gemma_rebuild_2026-10-01/validation/head-expansion-check-12.json), [분기 대조](../../copy_archive/gemma_rebuild_2026-10-01/validation/head-expansion-probe-02.json), [컴파일](../../copy_archive/gemma_rebuild_2026-10-01/validation/compile-15.json)에 기록한다. 전체 후보는 머리 13종·카드 134장·사건 112개, 독립 73개·후속 39개다. 맵 생성과 실제 플레이 검증은 수행하지 않았다. 다른 머리도 이어서 늘린다.

## 카라쿠라와 아메스트리스 확장

카라쿠라는 바느질·작은 인형·가족 보급·방송 촬영·불확실한 물품 묶음·연습 자리를 더해 독립 3개에서 9개, 전체 8개에서 14개, 카드 9장에서 13장으로 늘었다. 기존 배송·경보의 후속은 유지한다. 새 우류 카드의 행동3·치명피해15가 기존 레어 카드와 같은 축에서 모두 약해 차지6·치명피해15로 바꾸었다. [수정 전후](../../copy_archive/gemma_rebuild_2026-10-01/revisions/karakura-expansion-curation-10.json), [최종 채택](../../copy_archive/gemma_rebuild_2026-10-01/revisions/karakura-expansion-decision-11.json)을 보존한다.

아메스트리스는 반려견·사진·귀가 준비·정육점·식사 계산·군무·파이 상자를 더해 독립 3개에서 10개, 전체 7개에서 14개, 카드 8장에서 14장으로 늘었다. 알폰스의 식사 불가를 지키고 휴즈 생전·하보크 부상 전의 별도 만남으로 한정했다. [문장 수정](../../copy_archive/gemma_rebuild_2026-10-01/revisions/amestris-expansion-curation-13.json), [최종 채택](../../copy_archive/gemma_rebuild_2026-10-01/revisions/amestris-expansion-decision-13.json)을 보존한다.

신규 독립 13개·분기 69가지를 대조했다. 65/66·70/71 경계에서 실패 비용·보상, 지정 카드와 중복 교환, 개인 필드·행동력 1회, 머리 미소지 제외, 빈 골드와 필드 상한의 유효 선택을 확인했다. [검사](../../copy_archive/gemma_rebuild_2026-10-01/validation/head-expansion-check-13.json), [분기 대조](../../copy_archive/gemma_rebuild_2026-10-01/validation/head-expansion-probe-03.json), [스크립트 컴파일](../../copy_archive/gemma_rebuild_2026-10-01/validation/compile-16.json)에 기록한다. 현재 머리 13종·카드 144장·사건 125개, 독립 86개·후속 39개다. 실제 플레이 검증과 맵 생성은 하지 않았다. 다른 머리도 이어서 확장한다.

## 아비도스와 학원도시 확장

아비도스는 조깅 경로·낮잠 자리·간식 분배·골동품 기록·수족관 외출 준비·페로로 굿즈의 독립 사건6개와 카드5장을 더했다. 독립4개에서10개, 전체6개에서12개, 카드9장에서14장이다. 히후미는 트리니티 학생이며 호시노의 실종·학교 빚·본편 결말은 새 만남에서 해결하지 않는다. [원문과 효과 오인](../../copy_archive/gemma_rebuild_2026-10-01/revisions/abydos-text-rejection-14.json), [재집필의 수정 전후](../../copy_archive/gemma_rebuild_2026-10-01/revisions/abydos-expansion-curation-16.json), [채택](../../copy_archive/gemma_rebuild_2026-10-01/revisions/abydos-expansion-decision-16.json)을 보존한다.

학원도시는 소품 진열·간식 주문·이인삼각 준비·수영부 꾸러미·길목의 짐·밤 퍼레이드 표식의 독립6사건과 카드6장을 더했다. 독립4개에서10개, 전체6개에서12개, 카드9장에서15장이다. 아와츠키의 부력과 물 흐름을 구분하고 군하의 능력 원리는 확정하지 않았다. [문장 수정](../../copy_archive/gemma_rebuild_2026-10-01/revisions/academy-expansion-curation-18.json), [검토 원문 정상의 통과 분류 근거와 채택](../../copy_archive/gemma_rebuild_2026-10-01/revisions/academy-expansion-decision-18.json)을 남겼다.
