## 실행

시험 맵은 `C:\Users\ctqho\OneDrive\Documents\Warcraft III\Maps\mm\2\ARCRPG_RL_01.w3x`다. 원본 `ARCRPG.w3x`는 변경하지 않는다. 현재 사용 중인 JN 환경에서 실행한다.

1. 영웅을 선택한 뒤 마을에서 `M` 또는 화면의 `원정 [M]` 버튼을 누른다.
2. 참가한 사람 모두 `시험 원정 준비`를 누른다. 현재 1~4명, 일반 라이프 100으로 고정한다.
3. 시작 보너스를 고르고 하단에서 남은 포인트를 배분한다.
4. 우솝의 정찰에서 돌파 또는 우회를 투표한다. 돌파는 일반 전투, 우회는 무작위 물약 충전 후 개인 성장으로 이어진다.
5. 개인 보상, 개인 상점, 대표 보스, 결과 화면까지 진행한다. 일반 전투 실패는 라이프 손실 후 보상으로 이어지고, 마지막 대표 보스 실패는 시험 원정을 끝낸다.
6. 서버 연결 상태에서 승리했다면 결과의 저장 상태를 확인한다. 실패 시 `보관 재료 수령 · 저장 재시도` 또는 `-save`를 사용한다.

첫 게임 확인은 **1인 돌파 경로 완주**다. 그다음 2인에서 시간 초과, 전투 중 한 명 사망·이탈, 저장 후 재접속을 확인한다. 이미 확정한 승리 재료가 이후 실패로 사라지거나 재시도로 늘어나면 안 된다.

- 맵 전달 검사. 원본 맵에서 자동 생성 함수 17개를 그대로 추출. 원본 SHA-256 불변, 결과 스크립트 일치, 스크립트 외 목록 내 2,381개 파일 내용 불변 검사.

## 다시 빌드

`tools/build-expedition.py`는 원본 MPQ의 `war3map.j`와 활성 트리거 진입부를 읽어 현재 소스를 컴파일한다. 과거 JN 로그의 지형·유닛 배치를 재사용하지 않는다. 기존 출력 파일을 덮어쓰지 않으며, 활성 편집기 트리거 구조가 달라지면 중단한다.

```powershell
python tools/build-expedition.py `
  --source "C:\Users\ctqho\OneDrive\Documents\Warcraft III\Maps\mm\2\ARCRPG.w3x" `
  --output "C:\Users\ctqho\OneDrive\Documents\Warcraft III\Maps\mm\2\ARCRPG_RL_02.w3x" `
  --build-dir "$env:TEMP\arcana-roguelite-next" `
  --jn-root "C:\Users\ctqho\OneDrive\Desktop\JN" `
  --compiler-data "$env:TEMP\arcana2-click-fix-build" `
  --stormlib "<StormLib.dll의 절대 경로>"
```

`--compiler-data`에는 `common.j`, `Blizzard.j`, `pjass/f2d22c84.exe`가 필요하다. Python과 같은 비트수의 StormLib를 사용한다. 현재 Import.j는 기존 프로젝트의 절대 경로 형식을 유지한다. 다른 컴퓨터에서는 import 경로와 설치 경로를 맞춘다. 빌드 폴더의 입력/출력 스크립트와 네이티브 도구는 저장소에 올리지 않는다.
