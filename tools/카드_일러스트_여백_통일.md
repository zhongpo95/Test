# 카드 일러스트 여백 통일 모델팩

완성 파일은 `D:\Work\ARCANA\builds\asi\20261013_card_art_uniform\Arcana_A.asi`다.

현재 등록된 324종을 포함해 전체 카드 일러스트 438개를 검사했다. 182개는 완전히 투명한 바깥 여백을 제거하고 비율을 유지해 512×512를 채우도록 크롭했다. 세로 그림은 위쪽을 우선하며 전신 일부가 잘릴 수 있다. 캐릭터 윤곽 주변 투명도는 유지한다. 여백 없는 나머지 256개와 카드 이외 이미지 및 작은 아이콘은 이전 색상 수정 팩과 바이트가 동일하다.

전체 1,749개 파일을 포함한다. ASI는 155,925,848바이트이며 이전 색상 수정 팩보다 12,130,503바이트 늘었다. SHA-256은 `d1647353e479a45adac2b2138ce19ac977f58eb23d231144cbe03fc4fdb70283`이다.

게임 종료 후 기존 ASI를 백업하고 위 파일로 교체한다. BLP 경로 적용 맵은 변경할 필요가 없다. 게임 폴더에는 자동 설치하지 않았다. 원본 TGA 및 이전 팩도 보존했다. PR #214의 색상 수정도 포함한다.

정적/변환 검증으로 등록 카드 누락 0건, 전체 원본 해시 보존, 카드 이외 파일 불변, 밉맵 디코딩과 색상/투명도 회귀 검사를 확인했다. ASI 내부 모든 파일 해시 검증을 완료했다. 변경된 182개의 전후 비교표를 육안 확인했다. Warcraft 실게임 표시 및 멀티플레이는 미검증이다. JASS 변경과 맵 생성은 없다.

재생성은 `tools/BLP_모델팩_적용.md`의 변환 명령에 `--normalize-card-art`를 추가하고 새 출력 경로를 사용한다. 이후 동일 ASI 제작기로 패키징한다. 수정 변환기는 기존 투명 여백을 포함한 원본 TGA에서 실행한다.
