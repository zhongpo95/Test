# Gemma 로컬 구축 검토와 검증

2026-10-01, 실제 사용자 Windows PC에서 확인했다.

## 판단

번역과 사건·스토리 초안 제작용으로 구축 가능하다. Ryzen 7 9800X3D, RAM 약 32GB, RTX 3080 10GB, Windows 11 Pro, NVIDIA 드라이버 617.14를 확인했다. 최종 기본 모델은 `gemma4:12b-it-qat`이며 다운로드 크기는 7,151,003,754바이트로 약 7.2GB다. 설치 모델 정보와 digest는 [12B 실제 출력 기록](12b-실제출력.json)에 남겼다.

처음 시험한 E4B는 빠르지만 무료 100골드 선택을 보상 없는 떠나기로 바꾸는 오류를 반복했다. 경로가 포함된 번역 한 건도 보존 검사에서 거부됐다. [E4B 표본](e4b-실제출력.json)을 보관하고 더 큰 12B를 선택했다. 이는 네 개 표본의 비교이며 일반적인 품질 벤치마크는 아니다.

## 실제 모델 시험

12B를 동일한 네 표본으로 호출했다. 실제 GPU 추론이며 모의 응답이 아니다.

| 표본 | 실제 결과 | 전체 응답 시간 |
|---|---|---|
| 중국어 게임 설명 → 한국어 | 색상·줄바꿈·100골드·물약 1회 보존 | 최초 적재·준비 포함 약 25.7초 |
| 영어 설명 → 한국어 | 25%, {target}, %d, 실제 줄바꿈, 경로, rawcode 보존 | 약 0.8초 |
| 새 세계관 개인 사건 | A 무료 100골드, B 50골드 비용과 단서, C 무료 떠나기 포함 | 약 5.2초 |
| 홍마관 개인 사건 | A 물약 1회, B 100골드와 마도서 카드 1장, 무료 떠나기 포함 | 약 6.4초 |

준비 후 생성 속도는 약 69~71토큰/초였고 `/api/ps`는 8,192토큰 컨텍스트와 GPU 메모리 7,661,735,115바이트 적재를 보고했다. 실측 속도는 동시에 실행하는 게임이나 GPU 프로그램에 따라 달라진다.

품질 한계도 확인했다. 영어 번역의 `Icon`은 용어집을 제공해도 남았고, 사건의 짧은 분량 요구는 확실히 보장되지 않았다. 원작 고증, 선택의 서사적 설득력, 보상 이유와 밸런스는 별도 검토가 필요하다. 번역 검사는 서식과 값의 보존을 확인하며 의미의 정확성을 증명하지 않는다. 사건 모드의 보상 조건은 프롬프트로 지시하며 프로그램으로 의미 검증하지 않는다.

## 검토 대화 실제 모델 시험

후속 요청에 따라 초안 검토 대화와 Codex·터미널용 CLI를 추가했다. 같은 12B 모델을 사용하며 검토 컨텍스트 16,384토큰도 GPU에 모두 적재됐다. `/api/ps`가 보고한 메모리는 7,670,123,723바이트였다. 최초 요청·초안·참고 설정은 고정하고 이전 질문·답변과 현재 질문을 함께 전달했다.

[첫 시험 출력](review-1차-실제출력.json)에서는 주요 수치 오류를 찾았지만, 무료 100골드 조건을 지킨 '편지를 팔아 받는다'는 창작 표현까지 오류로 지적했다. 해당 표현을 허용하고 기존 지적도 틀릴 수 있다는 검토 기준을 보강했다. [최종 실제 출력](review-실제출력.json)에 아래 다섯 표본의 최초 자료, 대화 이력, 실제 결과와 실행 정보를 남겼다.

| 표본 | 최종 실제 결과 | 전체 응답 시간 |
|---|---|---|
| 잘못된 사건 초안 | A 50→100골드, B 파티 자원→개인 자원, C 유료→무료 떠나기 지적 | 약 5.9초 |
| 수정한 사건 후속 검토 | 변경된 조건을 인정하고 사용 가능 판정 | 약 1.7초 |
| 잘못된 번역문 | 100→50 변경과 `\|n` 누락 지적, 별도 프로그램 검사도 불일치 표시 | 약 2.0초 |
| 수정한 번역문 후속 검토 | 100과 `\|n` 복구를 인정하고 사용 가능 판정 | 약 1.7초 |
| 자료 없는 원작 정설 주장 | 근거 부족과 '원작 공식 설정' 문구 수정 필요 지적 | 약 4.3초 |

약 68~71토큰/초였다. 이는 작은 수의 기능 확인이며 일반적인 품질 평가나 원작 사실 검증이 아니다. 마지막 표본에서도 단서 구체화에 추가 표시를 요구하는 등 과도한 지적이 남았다. 검토 모델의 판정은 참고 의견이며 최종 확정은 사람이 한다. CLI의 실제 호출도 정상 응답을 확인했다. 번역 프로그램 검사는 처음 초안에만 적용되므로 후속 수정본의 판정과 구분해서 표시한다.

## 이미지 검토 실제 모델 시험

동일 모델의 이미지 입력을 연결하고 기존 프로젝트의 `assets/expedition/preview-start.png`와 `assets/expedition/rl04/preview-start.png`를 실제 전송했다. 두 이미지를 직접 눈으로 확인한 뒤 CLI로 첫 검토와 후속 시안 비교를 실행했다. [이미지 실제 출력](image-review-실제출력.json)에는 요청, 이력의 이미지 파일명·바이트 수·SHA-256, 응답, 실행 상태를 기록했다. 대용량 base64를 증거 파일에 중복 저장하지 않았다.

첫 이미지에서 7개의 카드와 하단 선택 버튼 위치를 읽었고, 후속 이미지에서는 6개로 바뀐 카드 수와 능력치 카드의 변경 내용을 구분했다. 전체 응답은 약 7.8초·4.3초, 생성 속도는 약 66~67토큰/초였다. 실제 이미지 인식과 이전 이미지 유지를 확인한 것이며 일반적인 OCR·시각 품질 성능을 증명한 것은 아니다.

오판도 있었다. 첫 응답은 실제로 여유가 있는 본문·버튼 간격을 가깝다고 지적했고, 후속 응답은 두 시안에서 동일한 골드 설명 문구도 변경됐다고 말했다. 가독성 의견과 변경 판단은 반드시 원본 이미지와 대조해야 한다. 이미지 속 게임 동작·고증·정확한 글자 인식은 이 시험으로 검증되지 않았다.

## 도구 검증과 전달 확인

- 정적·문법 검사 수행. Node `--check`, 화면 JavaScript 파싱, PowerShell 파서와 `git diff --check`를 확인했다.
- 모의 동작 검사 수행. 실제 HTTP 서버에 모의 모델 응답을 연결한 13개 검사를 통과했다. 호출 인증, 외부 페이지·Host 거부, 용도·크기 제한, 서식 손실·잘림·빈 응답 거부, 고정 로컬 모델, 중복 호출, 취소 전달, 메모리 해제를 포함한다. 검토의 최초 조건·초안·이전 답변·수정본 전달, 역할 위조와 빈 자료·대화 한도 거부, 모델 판정과 독립된 번역 불일치 반환도 확인했다. 이미지 단독 검토, 이전 이미지·수정 이미지 전달, PNG·JPEG 검증과 URL·과대 파일·해상도·개수·역할 위조 거부, 이미지로 넘친 텍스트 예산 거부도 포함한다.
- 실제 Windows 실행 수행. 공식 Ollama ZIP SHA-256 검증, 두 모델 다운로드와 모델 해시 검증, 전용 서버 시작과 종료를 확인했다. 종료 후 전용 추론 프로세스가 0개였고 중복 시작은 기존 PID를 유지했다.
- 실제 브라우저 시각 확인 수행. Codex 내장 브라우저에서 최종 12B 연결, 한국어 번역, 결과 표시와 클립보드 복사를 확인했다. Chrome의 `초안 저장`으로 실제 UTF-8 파일이 생성됐고 내용이 화면 결과와 일치했다. 내장 브라우저의 파일 다운로드는 확인하지 못했으므로 저장에는 Chrome을 권장한다. 화면 폭이 좁을 때 입력과 결과가 한 열로 바뀌는 모습도 확인했다.
- 검토 화면 시각·동작 확인 수행. 생성 당시 원문·결과를 검토로 가져오기, 첫 검토 후 최초 자료 고정, 후속 질문·수정본과 이전 대화 표시·복사를 확인했다. Chrome에서 PNG 이미지 첨부·미리보기·실제 검토를 확인했고 `자료·대화 저장`이 UTF-8 JSON 파일을 생성했다. 저장 파일에는 최초 요청, 실제 답변, 이미지 데이터가 포함됐고 이미지 SHA-256이 원본과 일치했다. 브라우저 WebP 변환과 큰 이미지 축소는 실제 파일 시험 없이 코드·문법 검사만 수행했다.
- Warcraft JASS 컴파일, 맵 패키징, 게임 실행·멀티플레이는 수행하지 않았다. 이 변경은 개발 도구만 추가하며 게임 파일을 편집하지 않는다.
- PR과 CI는 코드 전달 확인이다. CI의 모의 검사는 실제 Gemma 모델 추론이나 Warcraft 실행을 대신하지 않는다.

모델 추론은 전용 루프백 Ollama를 사용하고 `OLLAMA_NO_CLOUD=1`로 클라우드를 끈다. 모델 자체는 Apache 2.0으로 배포된다. [공식 모델 카드](https://ai.google.dev/gemma/docs/core/model_card_4), [12B QAT 배포](https://ollama.com/library/gemma4:12b-it-qat), [Ollama 로컬 설정](https://docs.ollama.com/faq)을 확인했다.
