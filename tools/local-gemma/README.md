# 로컬 Gemma 번역·사건 제작

Gemma 4 12B QAT을 이 PC에서 실행하는 프로젝트용 도구다. 번역과 사건·스토리 초안 두 모드를 제공한다. 결과를 검토한 뒤 복사하거나 UTF-8 텍스트로 저장한다.

## 실행

1. 처음에는 `설치.cmd`를 실행한다. Ollama 실행 파일 약 1.46GB와 모델 약 7.2GB를 받는다. 실행 파일은 고정 버전 v0.35.0과 공식 SHA-256으로 검증한다. 모델 다운로드도 Ollama가 해시를 검증한다.
2. `시작.cmd`를 실행한다. [작업 화면](http://127.0.0.1:18765)이 브라우저에서 열린다.
3. 번역 모드에서 문장·아이템 설명과 용어집을 입력하고 목표 언어를 선택한다. 스크립트 전체 대신 번역할 텍스트만 입력한다.
4. 사건 제작 모드에서 세계관과 요청을 입력한다. 기존 `Data/Data_Prototype.j`의 해당 세계관 사건 일부를 참고하며, 원작 고증을 확인한 것으로 간주하지 않는다. 고정할 비용·보상·확률은 요청에 명시한다.
5. 필요한 결과를 복사하거나 `초안 저장`으로 저장한다. 입력과 결과의 자동 저장 기능은 없다.
6. 게임 시험 전에는 `GPU 메모리 해제`를 누른다. 완전히 닫을 때는 `종료.cmd`를 실행한다.

Windows 10 22H2 이상, Node.js 22 이상, NVIDIA 드라이버 551.61 이상이 필요하다. Node가 PATH에 없으면 Codex의 번들 Node 경로를 확인한다. 관리자 설치·로그인 자동 시작·시스템 환경 변수 변경은 하지 않는다.

## 구성과 한계

- 모델과 실행 로그는 `%LOCALAPPDATA%\ArcanaGemma`에 저장된다. OneDrive와 Git에 대용량 모델을 넣지 않는다.
- 전용 Ollama는 `127.0.0.1:11435`, 작업 화면은 `127.0.0.1:18765`에서만 수신한다. `OLLAMA_NO_CLOUD=1`로 클라우드 기능을 끄고 모델명을 서버에서 고정한다.
- 원격 추론, 파일 편집, 코드 실행 도구는 연결하지 않는다. Gemma의 답변은 텍스트로만 표시된다. 직접 적은 요청이 용도를 벗어난 답변을 유도할 가능성까지 모델 수준에서 막는 것은 아니다.
- 입력은 4,000자, 용어집은 1,500자로 제한한다. 컨텍스트 8,192토큰, 출력 최대 3,072토큰, 동시 생성 1개, 요청 제한 5분이다. 긴 글은 나눠 입력한다. 출력이 잘리면 오류로 알린다.
- 번역의 색상 코드, `|n`, `|r`, 실제 줄바꿈, 숫자, `{변수}`, `%s`/`%d`, `'I0CC'` 형태 rawcode와 영문 경로는 출력 후 원문과 대조한다. 서식의 순서가 바뀌거나 값이 누락·변경·중복되면 결과를 거부한다. 번역 어순에 따른 변수 위치 이동은 허용한다. 임의의 JASS/Lua 식별자나 모든 포맷 문법을 보존하는 소스 번역기는 아니다.
- 일반 번역은 낮은 온도 0.1, 사건 초안은 0.8로 생성한다. 한국어 자연스러움·장편 연속성·원작 고증·밸런스는 사람의 검토가 필요하다. 소형 모델의 초안을 최종 확정 문장으로 간주하지 않는다.
- 요청을 마친 모델은 2분 뒤 자동 해제한다. 중단 버튼은 서버의 모델 요청도 취소한다. 화면을 닫아도 서버는 유지되므로 `종료.cmd`로 닫는다.
- 종료는 이 도구가 기록한 PID·실행 경로·시작 시각이 모두 일치하는 프로세스만 대상으로 한다.

## 검증

`node --test tools/local-gemma/check.cjs`는 실제 HTTP 서버와 모의 모델 응답으로 호출 제한, 서식 보존, 잘린 답변, 동시 호출, 메모리 해제를 검사한다. 실제 Gemma 출력과 속도는 별도 [검증 기록](검증기록.md)에 구분해 적는다.
