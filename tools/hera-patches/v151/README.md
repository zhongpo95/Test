# Hera RPG v151 야에 사쿠라 공중 형태 E 해제 수정

지상에서 정상 작동하던 E가 공중 형태로 바뀐 뒤 충전만 계속되고 발도하지 않는 문제를 수정했습니다.

## 로그와 코드에서 확인한 원인

v150 입력 로그에서 영웅 핸들은 그대로인데 종류가 H02D(지상)에서 H02F(공중)로 바뀝니다. 336.670초에 지상 형태에서 E를 시작했고, 339.220초 기록에서 공중 형태가 확인되며 이후 키를 떼어도 A1S0 해제 스킬이 발동하지 않습니다. 전환 전에는 E 시작과 A1S0 해제 기록이 14쌍 있습니다.

H02F는 별도 영웅이 아니라 기존 야에 사쿠라의 공중 형태입니다. 영웅 등록과 비행 처리, 능력 오브젝트의 H02D/H02F 연결로 확인했습니다. 게임의 `u.type`은 최초 영웅 종류를 저장하며 비행과 기존 E 입력은 이 값을 사용합니다. v150 수신기에 추가했던 현재 `GetUnitTypeId` 검사가 공중 형태를 거부했습니다.

일반 해제 진단은 기존 40건 제한에 도달해 후반부 상세 수신 기록이 없습니다. 이는 기록만 제한하며 명령 실행을 중단하는 조건은 아닙니다. 실제 기록의 형태 전환과 정적 조건을 대조하고 보존한 v150 수신기로 모의 재현했습니다.

## 수정

- 수신기의 야에 판별을 기존 입력·비행 처리와 동일한 `u.type` 기준으로 통일했습니다.
- 소유자, 유닛 수명, 생존, 충전 상태와 A1S0 보유 검사는 유지합니다.
- v150의 8바이트 동기화 이름, 기존 충돌 입력 함수 회피도 유지합니다.
- E 충전·피해·수치·기류 이펙트 수명은 변경하지 않았습니다.

## 검증

- Lua 모의 검사 93개 통과. 현재 엔진 종류와 캐시된 원래 영웅 종류를 분리했습니다. 실제 v150 수신기로 공중 E의 해제 누락을 재현했고, v151은 동일 조건에서 해제 명령과 참격이 한 번 실행되고 기류 생성 루프가 끝납니다.
- 두 클라이언트, 지상·공중 형태, 충전 중 비행 전환, 해제 전송 후 수신 전 착지, 짧은·긴·반복 충전, 잘못된 소유자 및 다른 영웅의 공중 종류 위장·중복 요청을 검사했습니다.
- 정적 검사 완료. 추출 Lua 593개 문법, 수정 포함 및 원본 E/A1S0 유지 확인.
- 빌드·패키지 검사 완료. MPQ 5,652개 블록 해시·파일 조회 검사 통과.
- 실제 Warcraft 실행, 실제 네트워크 전달과 멀티 동기화, 화면 검증은 미실시입니다. JASS 로직 변경 및 JASS 재컴파일은 없습니다.

v151에서 공중 상태로 E를 충전한 뒤 떼어 기류가 멎고 발도하는지 확인합니다. 충전 중 지상·공중이 바뀌어도 같은 동작을 기대합니다.

맵 SHA256 `2753ace32efe68cec3f0e72162f281ecef39f455587813c7a5fe19d839d10b7f`

## 원본 작업 폴더에 적용

맵 원본과 모델팩은 이 저장소에 포함하지 않습니다. 별도 Hera RPG 작업 폴더의 v148을 보존한 복사본에서 아래를 실행합니다. 모의 검사에는 Lua 5.3을 포함한 Lupa가 필요하고 검사에는 독립 검증기로 추출한 v148/v150/v151 소스가 필요합니다. v150 추출본은 기존 공중 해제 누락을 재현하는 기준 수신기로 사용합니다.

```powershell
$patchDirectory = '검토한 패치 디렉터리의 절대 경로'
git apply --check "$patchDirectory/integration.patch"
git apply "$patchDirectory/integration.patch"
Copy-Item -LiteralPath "$patchDirectory/yae_release.lua" -Destination './hera-port/scripts/gameplay/feature/shot/yae_release.lua'
python build_hera_rpg.py
node validate_hera_rpg.js Hera_RPG_Init_v151.w3x hera-rpg-validation-v151
python "$patchDirectory/check_v151.py" (Get-Location).Path
python "$patchDirectory/check_packaged_v151.py"
```

현재 위치는 v148 맵 작업 폴더입니다. `integration.patch`는 v148 대비 기존 파일 수정이고 새 모듈은 `yae_release.lua`입니다. v148이 아닌 폴더에는 이 누적 패치를 적용하지 않습니다.
