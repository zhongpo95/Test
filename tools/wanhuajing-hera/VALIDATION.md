# v12 검증

- v11의 모델 1,402개 TEXS 경로 수정과 3,029개 BLP 연결 복구를 유지한다.
- 부착 효과 숨김/재표시, 숨긴 동안 크기 변경, 크기 0, 제거 및 핸들 재사용 Lua 회귀 검사 통과.
- MPQ 압축 경계, 복호화, 손상 모델 거부, LNI 상속·열거값·문자열 정적 검사 통과.
- 전체 Lua 문법과 초기화 모의 검사 727모듈·135프레임·1,001 타이머 콜백 통과.
- PJass 생성 JASS 3,059줄 통과.
- 전체 MPQ 검사 결과는 staging/verification.json에 기록한다.
- 실제 헤라 v12 실행·효과 표시·PVE 진행·멀티플레이·시각 검증은 미실시.
- 서버 저장과 전용 렌더/조준 입력 등 미지원 범위는 COMPATIBILITY.md 참조.

원본/생성 맵, DLL, 실행 중 수집 코드는 저장소에 포함하지 않는다.
