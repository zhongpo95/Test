# 묵시록 v205 MP 채팅 및 난이도 초기화 수정

최신 전달본은 v205 MP다. 사용자 v204 상태창의 `Status = BLOCKED`, `Module = main`, `hera_ui_bridge.lua:164: ... Call jass function crash.<TriggerEvaluate>`를 확인했다. 164행은 `FrameShow` 경로이며 v204에서 기본 채팅 프레임에 추가한 숨김 호출을 제거했다. 투명도 0과 화면 밖 배치, 외침 도구와 로그 중지 변경은 유지한다.

v205에서는 실제 `scripts/main.lua`와 난이도 로더를 사용한 모의 실행으로, 채팅 FrameShow에 같은 오류를 주입하면 v204 초기화가 중단되고 v205는 난이도 UI 로딩과 입력 연결까지 도달하는 것을 확인했다. 커스텀 UI 켜짐·꺼짐, 채팅 프레임 0을 검사했다. 실제 게임 화면과 멀티플레이는 미검증이다.

```powershell
python tools/hera-chat/build_v205.py <Hera_RPG_Init_v204_MP.w3x> <output/Hera_RPG_Init_v205_MP.w3x>
python tools/hera-chat/check_v205.py <Hera_RPG_Init_v204_MP.w3x>
```

v205 전달 검사는 변경 멤버 4개 재추출 일치, 나머지 5,658개 블록 및 해시 테이블 불변과 pjass 정적 검사 통과다. 게임 기능 변경은 채팅 FrameShow 한 줄 제거뿐이며 나머지 3개 멤버는 버전 표시다. v204는 아래 재현 및 빌드 이력으로만 보존한다.

## v204 변경과 검사 이력

v203 MP에서 기본 채팅과 커스텀 채팅이 겹쳐 표시되고 Alt+숫자 외침이 동작하지 않는 제보를 반영한다. 사용자가 안정화 후 중지해 달라고 요청한 진단 로그는 주석으로 보존한다.

- 기본 채팅 프레임에 숨김, 투명도 0, 화면 밖 좌표를 함께 적용한다. 커스텀 채팅과 시스템 안내는 유지한다.
- 외침 도구의 키 누름·뗌을 로컬 Dz JASS 이벤트에 연결하고 키 상태를 DzIsKeyDown으로 조회한다. 기존 창 이벤트와 같은 상태를 공유해 자동 반복과 중복 전달을 억제한다.
- 기본 Alt+1~0, 사용자 지정 1키·2키, 문구 및 단축키 저장, 명령어 이력은 유지한다. 키 기록 중·문구 편집 중·기본 채팅 입력 중에는 외침을 보내지 않는다.
- 기존 T키 이모티콘 콜백 안에서 외침 입력을 함께 전달하므로 T키를 중복 등록하지 않는다. 마우스 네이티브 경로도 외침 편집창의 포커스 추적에 연결한다.
- 부트·순환 파일·초기화·게임 상태·이탈·UI·이동·아이템·핸들 진단과 print/log의 기록 본문을 긴 주석으로 보존한다. 기록 전용 주기 검사와 이벤트 설치도 주석 처리한다. 건물 지연 콜백 취소, 핸들 세대 및 참조 수명, 피해 적용은 유지한다.

`patch.py`는 해시가 고정된 v203 원본의 필요한 멤버만 수정한다. `build.py`는 기존 출력 덮어쓰기를 거부하고 맵, 수정 소스, 변경 diff와 해시 보고서를 생성한다. 원본과 변경 멤버의 줄바꿈 방식도 보존한다. 원본 맵과 이전 로그 파일은 삭제하지 않는다.

## 빌드 및 검사

```powershell
python tools/hera-chat/build.py <Hera_RPG_Init_v203_MP.w3x> <output/Hera_RPG_Init_v204_MP.w3x>
python tools/hera-chat/check.py <Hera_RPG_Init_v203_MP.w3x>
```

빌드는 Python 표준 라이브러리만 사용하며 모의 검사에는 `lupa.lua53`이 필요하다.

- 정적 검사. 변경 Lua 19개 및 완성 MPQ의 Lua 전체 602개가 Lua 5.3 구문 검사를 통과했다.
- JASS 검사. 설치된 Warcraft의 common.j/Blizzard.j와 pjass로 최종 war3map.j 구문·타입 검사를 통과했다. 게임 실행용 컴파일이나 실제 로딩 검사는 하지 않았다.
- Lua 모의 실행. Alt+1~0, 역순 입력, Alt 유지, 키 반복, 중복 이벤트, 3키 차단, 채팅·편집·비활성 창 보호, 단축키 기록·취소·중복 거부, 문구 길이 제한, 저장 후 복원, 수신 시 한 번의 명령 전달을 검사했다.
- 로그 및 보호 로직 모의 실행. 파일·콘솔 기록이 발생하면 실패하는 환경에서 진단 함수와 출력 함수를 호출했다. 건물 지연 콜백 취소와 핸들 재사용 세대 보호, 피해 함수 반환을 별도로 확인했다.
- 전달 검사. 변경 멤버 22개의 재추출 일치, 나머지 5,640개 블록 및 MPQ 해시 테이블 불변을 검사했다.
- 미수행. 실제 Warcraft 실행, Alt키 이벤트 도착, 인게임 시각 검사, 멀티플레이 및 크래시 안정성 검증.
