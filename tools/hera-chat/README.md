# 묵시록 v211 MP 한글 자모 폰트 판별 수정

한글 판별이 완성형 음절 U+AC00~D7A3만 포함해 `ㅋㅋ`, `ㅎㅎ`, `ㅁㄴㅇ`, `ㅏㅓㅗ`만 있는 채팅은 한국어 폰트로 전환되지 않았다. 실제 맵의 gamefont.ttc에는 해당 글자가 없고 NanumGothic-Regular.ttf에는 있으므로 호환 자모 U+3131~318E도 한글로 판별한다. 기존 완성형·영문 동작과 채팅 내용은 유지한다.

사용자는 멀티플레이 처음에 한글이 보이지 않았다가 현재 전부 보인다고 추가 확인했다. 이 일시적 현상과 자모 판별 누락이 동일한 원인인지는 확인되지 않았다. v211은 재현한 자모 판별만 수정하며 초기 멀티 표시 문제 해결을 주장하지 않는다.

```powershell
python tools/hera-chat/build_v211.py <Hera_RPG_Init_v210_MP.w3x> <output/Hera_RPG_Init_v211_MP.w3x>
python tools/hera-chat/check_v211.py <Hera_RPG_Init_v210_MP.w3x>
```

실제 채팅 표시 함수·글자 컨트롤·번역 모듈·폭 자료를 Lua 5.3에서 실행해 기존 자모 폰트 전환 누락과 수정 후 전환, 원문 보존, 완성형·영문 회귀를 검사했다. 실제 폰트 문자표도 읽기 전용으로 대조했다. MPQ 변경 4개 멤버 재추출 및 5,658개 블록·해시 테이블 불변을 확인했다. v211 실제 게임·시각·멀티플레이 검사는 미수행이다.

## v206 외침 실행 및 선택 전 채팅 이력

v206 변경 이력이다. 사용자는 키 변경은 가능하지만 외침 실행이 되지 않으며, 영웅 선택 전에는 기본 채팅만 보인다고 확인했다.

- 설치된 YDWE DLL에는 `GetChatState`가 없다. 기존 코드로 해당 API가 없는 환경을 모의 실행하면 키 기록은 성공하지만 일반 키 입력은 오류로 중단됨을 재현했다. 지원되는 환경에서는 기존 API를 사용하고, 없는 환경에서는 Enter/Esc와 로컬 채팅 수신으로 입력 상태를 추적한다. 채팅을 키보드 이외의 방법으로 여닫는 경로는 실제 게임 확인이 필요하다.
- 외침 수신 시 기본 채팅 출력 호출을 제거하고 기존 `dispatch_chat`으로 한 번 전달한다. 사용자 지정 문구·단축키 파일은 변경하지 않는다.
- 영웅 선택 전 채팅 처리기가 없는 플레이어도 기존 커스텀 채팅 표시 함수를 호출한다. 선택 후에는 기존 명령 처리와 표시를 그대로 사용한다.
- 일반 채팅 이벤트 뒤 1ms 지연 호출로 기본 채팅의 투명도·화면 밖 배치를 다시 적용한다. 엔진이 새 메시지 처리 때 배치를 복구하는 경우를 대상으로 한 수정이며, 실제 숨김 유지 여부는 아직 미검증이다. v205에서 제거한 채팅 `FrameShow`는 다시 추가하지 않는다.
- 난이도 초기화 복구와 진단 로그 주석 처리는 유지한다.

```powershell
python tools/hera-chat/build_v206.py <Hera_RPG_Init_v205_MP.w3x> <output/Hera_RPG_Init_v206_MP.w3x>
python tools/hera-chat/check_v206.py <Hera_RPG_Init_v205_MP.w3x>
```

검증은 Lua 5.3 구문·모의 실행과 MPQ 변경 범위 검사다. 실제 게임 실행, 화면 검사, 멀티플레이 검사는 수행하지 않았다.

## v204 변경과 검사 이력

v203 MP에서 기본 채팅과 커스텀 채팅이 겹쳐 표시되고 Alt+숫자 외침이 동작하지 않는 제보를 반영한다. 사용자가 안정화 후 중지해 달라고 요청한 진단 로그는 주석으로 보존한다.

- 기본 채팅 프레임에 숨김, 투명도 0, 화면 밖 좌표를 함께 적용한다. 커스텀 채팅과 시스템 안내는 유지한다.
- 외침 도구의 키 누름·뗌을 로컬 Dz JASS 이벤트에 연결하고 키 상태를 DzIsKeyDown으로 조회한다. 기존 창 이벤트와 같은 상태를 공유해 자동 반복과 중복 전달을 억제한다.
- 기본 Alt+1~0, 사용자 지정 1키·2키, 문구 및 단축키 저장, 명령어 이력은 유지한다. 키 기록 중·문구 편집 중·기본 채팅 입력 중에는 외침을 보내지 않는다.
- 기존 T키 이모티콘 콜백 안에서 외침 입력을 함께 전달하므로 T키를 중복 등록하지 않는다. 마우스 네이티브 경로도 외침 편집창의 포커스 추적에 연결한다.
- 부트·순환 파일·초기화·게임 상태·이탈·UI·이동·아이템·핸들 진단과 print/log의 기록 본문을 긴 주석으로 보존한다. 기록 전용 주기 검사와 이벤트 설치도 주석 처리한다. 건물 지연 콜백 취소, 핸들 세대 및 참조 수명, 피해 적용은 유지한다.

`patch.py`는 해시가 고정된 v203 원본의 필요한 멤버만 수정한다. `build.py`는 기존 출력 덮어쓰기를 거부하고 맵, 수정 소스, 변경 diff와 해시 보고서를 생성한다. 원본과 변경 멤버의 줄바꿈 방식도 보존한다. 원본 맵과 이전 로그 파일은 삭제하지 않는다.
