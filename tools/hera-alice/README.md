# 앨리스 대화 잠금 수정 v179

대화 후 다른 앨리스 카드까지 우클릭이 차단되는 것은 의도된 제한이 아니다. 원본은 송신 후 공통 잠금을 설정하고 수신 시 해제한다. 즉시 수신하면 해제 후 다시 잠기며, 수신이 누락되면 잠금이 영구 유지된다. 실제 리플레이와 로그에는 잠금 값이 기록되지 않아 당시 어느 경로가 발생했는지는 확정하지 못했다.

이 수정은 잠금을 송신 전에 설정하고 ASCII 동기화 키 `AliceUI`를 사용한다. 요청 번호로 이전 응답과 현재 요청을 구분한다. 송신 예외 또는 10초 미수신 시 로컬 메뉴 잠금만 해제하며, 게임 효과를 자동 재실행하지 않는다. 응답 전 같은 카드·행동을 재시도하면 같은 요청 번호를 재사용하며, 플레이어별 수신 기록으로 한 번만 적용한다. v178에서 발견된 타임아웃 후 늦은 요청과 재시도의 중복 처리 가능성을 v179에서 보완했다. 대화, 서약, 보상 및 사망한 카드의 상호작용 제한은 원래 처리 코드를 유지한다.

## 빌드

Python 표준 라이브러리만 필요하다. 보유한 검증된 v177 파일을 입력한다. 소스 SHA-256 불일치 및 기존 출력 덮어쓰기를 거부한다.

```powershell
python tools/hera-alice/build.py C:/maps/Hera_RPG_Init_v177_MP.w3x C:/maps/Hera_RPG_Init_v179_MP.w3x
```

기존 아카이브에 변경 항목을 추가하고 블록 참조만 교체한다. 앨리스 Lua, `-hera` 표시 제목, 빌드 식별자, 로비 이름 및 맵 정보만 바뀐다. 원본과 나머지 5,656개 블록 및 해시 테이블은 보존한다. 출력 옆 JSON에 검사 결과를 기록한다.

## 검증

`lupa==2.8`을 설치한 Python에서 다음 검사를 실행한다. 입력은 v177에서 추출한 `scripts/gameplay/var/pools/mwx/pools_mwx_alice.lua`이다.

```powershell
python tools/hera-alice/test_fix.py C:/extracted/pools_mwx_alice.lua
python tools/hera-alice/test_progress.py C:/extracted/pools_mwx_alice.lua
```

- 수행. 전체 수정 Lua 구문 검사, 실제 송수신 콜백의 즉시·지연 응답, 중복 클릭, 송신 예외, 타임아웃, 이전 응답, 영웅 없음, 잘못된 응답 및 다른 플레이어 응답 검사.
- 수행. 원본 콜백에서 즉시 응답 시 영구 잠금 재현, 패키징 후 변경 파일 재추출 일치 검사.
- 수행. 실제 이벤트 함수의 원본/수정본 12개 진행 결과 비교, 실제 서약 함수의 지연 중복 수신 시 비용과 효과 단일 적용, 플레이어별 요청 분리 및 정상적인 후속 반복 행동 검사.
- 미수행. Warcraft 실제 실행, 시각 검사 및 멀티플레이 검증. v179에서 대화 후 다른 앨리스 카드 우클릭, 서약 1회 적용, 일반 카드 우클릭을 확인해야 한다.

이 도구는 원본 맵이나 게임 리소스를 저장소에 포함하지 않는다. 관련 이슈는 #131이다.
